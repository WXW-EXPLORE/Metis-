# E008：等状态对照（E008a）与 N1 键表示（E008b）

脚本：`run.py`。原始：`raw.csv`；汇总：`summary.csv`；配置：`config.json`。
复现（仓库根目录）：`PYTHONPATH=src python experiments/E008_controls/run.py --out experiments/E008_controls`

## E008a：RLS K1 与等状态 GDN 对照

- RLS K1 的状态为 $M(64\times64)+P(64\times64)$，共 $2\cdot64^2$。
- GDN K=2 满维度库（top-1 随机路由）的状态为 $2\cdot64^2$，等大。
- GDN 的 α 取 0.99 与 0.999，分别与 RLS 的 λ 对应。

| ρ | n | RLS K1 | GDN K2 (α=0.99) | GDN K2 (α=0.999) |
|---|---|---|---|---|
| 0.1 | 128 | **+0.752** | +0.375 | +0.640 |
| 0.3 | 32 | **+0.706** | +0.153 | +0.198 |
| 0.3 | 128 | **+0.401** | +0.047 | +0.063 |
| 0.6 | 32 | **+0.415** | −0.086 | −0.079 |

年龄曲线（age=256）：RLS 0.441，GDN α=0.999 为 0.099，GDN α=0.99 为 −0.008。

**结论（已验证）**：在等状态下，RLS 的优势仍然存在且明显。因此 N7（"提升可能只来自多存的状态"）**在这一对照下不成立**。注意：GDN 的对照只有一种分库方式（top-1 随机路由）；更多的 GDN 对照（如单库加更大维度）尚未做。

## E008b：N1 的键表示（等参数分库，RLS，K=4，d_b=16，top-1）

| ρ | n | 随机投影（N1 原方案） | 坐标分块 |
|---|---|---|---|
| 0.0 | 32 | 0.923 | 0.934 |
| 0.0 | 128 | 0.490 | 0.471 |
| 0.3 | 128 | 0.228 | 0.244 |
| 0.6 | 128 | 0.134 | 0.188 |

**结论（已验证）**：坐标分块与随机投影没有可分辨的差异。ρ=0 时 n=128 的召回仍只有约 0.48（基线 K1 为 1.00）。原因（推断，与数值一致）：投影后，目标键与干扰键在库内不再正交，因此 ρ=0 的"目标与查询正交"结构被破坏。这与投影的方式无关。

**决定**：等参数分库在键维度固定时无法保留这一结构。按"不做过大代价"的原则，分库保留为可开关选项（满维度键，代价为 $K$ 倍状态）；默认采用单库加 RLS。
