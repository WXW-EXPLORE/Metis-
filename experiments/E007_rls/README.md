# E007：0a-v2 RLS 更新规则的验证

设计：`docs/design_0a.md` §10。实现：`src/holistic/banked_memory.py`（`update_rule="rls"`）。单元测试：`tests/test_banked_rls.py`（17 项通过）。
与 E006 相同的数据、种子与配置，只改变更新规则：E006 为 GDN（固定增益），E007 为 RLS（增益由协方差 $P$ 解析给出）。

复现（仓库根目录）：`PYTHONPATH=src python experiments/E007_rls/run.py --out experiments/E007_rls`

文件：`raw.csv`、`summary.csv`（5 个种子）、`config.json`。

## 已验证的理论性质（单元测试）

- $\lambda=1$ 时，RLS 状态与协方差等于带岭项 $\delta$ 的最小二乘解（误差 $10^{-8}$）。
- 零值写入后，$\kappa^\top M$ 按 $\lambda/(\lambda+\kappa^\top P\kappa)$ 缩放，与理论极点一致。
- 协方差长序列后保持正定；迹受 $p_{\max}$ 限制。
- **带遗忘的精确降秩**：删除第 $j$ 条（年龄 $T-j$）后，状态、协方差、键质量与"把第 $j$ 步换成零权重写入"的参考逐元素一致（误差 $10^{-8}$）。依据：信息形式下第 $j$ 条的权重是 $\lambda^{T-j}w_j$，降秩即撤销该权重。

## 结果（均值，5 个种子；E006 GDN → E007 RLS）

### M1：分库与路由的召回余弦（越高越好）

| 配置 | ρ | n=32 | n=128 |
|---|---|---|---|
| K1 | 0.1 | 0.751 → **0.938** | 0.197 → **0.536** |
| K1 | 0.3 | −0.010 → **0.672** | 0.102 → **0.246** |
| i（top-1） | 0.3 | 0.268 → **0.776** | −0.025 → **0.228** |
| i（softmax） | 0.0 | 0.702 → **0.832** | 0.039 → **0.343** |

RLS 在所有配置上都更好。等状态对照（E008a）表明，这一优势**不是**因为多存了协方差（见 E008 README）。

### M2：年龄曲线（目标召回余弦）

|---|---|---|---|

| α=0.999 | 0.877 → 0.969 | 0.404 → 0.795 | 0.138 → 0.440 |
| 快慢两库（top-1） | 0.801 → 0.977 | 0.240 → 0.704 | 0.055 → 0.241 |

### M3：显式删除（n=32，判据为精确删除，即与"从未写入目标"的参考比较）

| 配置 | ρ | 误伤（相对参考） | 目标残留（相对参考） |
|---|---|---|---|
| K1 | 0.1 / 0.6 | $0$ / $0$ | $10^{-15}$ / $10^{-15}$ |
| i（softmax） | 0.1 / 0.6 | $0$ / $0$ | $10^{-16}$ / $10^{-16}$ |
| i（top-1） | 0.1 / 0.6 | $0$ / $0$ | $10^{-15}$ / $10^{-15}$ |

删除精确（残留与误伤均为浮点舍入量级）。K1、ρ=0 的相对残留为 $3\times10^{-3}$，原因是参考读出本身只有 $1.7\times10^{-15}$，相对误差被放大；绝对误差约 $3\times10^{-15}$，属于舍入（已验证）。

**注意**：M3 的指标定义在 E007 中改为与参考比较。E006 的 M3 使用的是删除前后的变化量，两者不可直接比较。

## 结论

- RLS 的召回与年龄曲线明显优于 GDN（已验证，见 E008a 的等状态对照）。
- 带遗忘权重的精确降秩使删除对任意 $\lambda$ 都精确，前提是条目年龄已知（已验证）。这修正了之前 N6 的结论。
- 年龄信息需要由调用方（或模块的写入计数）保存；这是接口上的新增要求。

## 限制

1. 删除精确的前提是年龄已知。若年龄未知，$\lambda<1$ 的库退回投影删除并计数（此时残留与误伤都不为零，需要报告）。
2. 所有结果都是合成数据、各向同性的键；真实键分布下的结论需要阶段 1 验证。
