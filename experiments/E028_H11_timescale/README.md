# E028（H11 / G4）：多时间尺度（快、慢两组）的离线评估

设计：`docs/design_H11_timescale.md`（§10 修订）。键：预训练 Metis-4B，RLS（`abs` 读出）开环录制，全部 8 层保存（`/hy-tmp/e028_keys.pt`，26.7 GB）。评估：`eval.py`，结果：`results/result.json`。

## 1. 设置

- 划分：调参 = 第 4–5 个对话（135 个 episode）；测试 = 第 6–10 个对话（295 个 episode）；拟合（PCA 基与原型）= 前 3 个对话。
- 层：记忆层 3 与 7。
- 臂（等总状态 1024 行）：
  - S1：单库，1024 行，λ = 0.9，全键。
  - T2L：两组各 512 行，PCA-512 键，竞争学习路由（K=2），快组 λ_f、慢组 λ_s。
  - T2R：同 T2L，随机路由中心（3 个种子）。
- 度量：保留曲线的 AUC（年龄 = 之后的写入次数，a ∈ {1, 2, 4, 8, 16}），逐 episode 配对，bootstrap 95% 区间。

## 2. λ 选择（仅在调参集上）

网格 λ_f ∈ {0.3, 0.5, 0.7}，λ_s ∈ {0.95, 0.99, 0.995}。最佳：**λ_f = 0.3，λ_s = 0.95**（平均差 +0.0052，检出下限 0.0009，可检出）。

⚠️ 最佳值位于网格边界（λ_f 最小、λ_s 最小）。真正的最优可能在网格之外，需要预先登记新的网格才能检验。

## 3. 测试集判据（λ 锁定）

| 判据 | 层 3 | 层 7 | 结论 |
|---|---|---|---|
| G4-a：T2L − S1 | +0.0067 [0.0065, 0.0069] | +0.0051 [0.0042, 0.0059] | 通过 |
| G4-b：T2L − T2R | +0.00025 [0.00003, 0.00047] | +0.0020 [0.0018, 0.0022] | 通过 |
| G4-c：T2L 最小组占比（token） | 0.42 | 0.42 | 通过（≥ 0.2） |

绝对保留曲线（AUC）：S1 0.955（层 3）/ 0.954（层 7）；T2L 0.962 / 0.959；T2R 0.962 / 0.957。

## 4. 解读与限制（⚠️ 条件成立）

1. **效果很小**：自检索余弦的差约 0.005（层 3 的 G4-b 仅 0.00025）。统计上可区分，但实际影响很小。
2. **投影混杂**：T2 使用 PCA-512 键，S1 使用全 1024 键。G4-a 中 T2L 优于 S1，尽管 T2 损失了投影信息，因此方向上不利于 T2。但没有"PCA-512 单库"的对照，无法把投影影响与时间尺度效应完全分开。
3. **单一划分**：T2L 的学习路由在三个种子下是同一划分（E027）。G4-a 与 G4-b 的区间只反映 episode 抽样，不反映划分的变异。T2R 的三个种子是独立划分，已取平均。
4. **λ 位于边界**：选出的快组 λ_f = 0.3 意味着快组几乎只保留最近几次写入。它的收益可能主要来自"快组接收新写入、慢组保留历史"的分工，而不是某个精确的时间常数。
5. **零样本**：只评估记忆的保留，不评估回答质量。
6. **开环键**：键在 RLS 的开环状态下录制（与 G1 相同）。闭环中键会随记忆改变（N10），这里没有考虑。

## 5. 结论（按设计登记的规则）

按预先登记的判据，G4-a、G4-b、G4-c 均通过：在等总状态下，按内容分配的快慢两组保留的信息比单库多，并且比随机分配的快慢两组多（方向一致，效果小）。

这一结论只适用于：零样本、开环键、所选 λ（位于网格边界）、以及本数据集。它不能直接推出训练后的收益，也不能说明收益来自双时间常数本身（需要 T2L 与"PCA-512 单库"的对照）。

## 6. 补充对照（探索性，主判定之后补充；`eval_controls.py`，`results/controls.json`）

λ 沿用锁定值。这些对照不改变第 5 节的判定。

| 分解 | 层 3 | 层 7 | 含义 |
|---|---|---|---|
| S1p − S1 | −0.0013 [−0.0013, −0.0012] | −0.0017 [−0.0017, −0.0016] | PCA-512 投影的成本（负值 = 投影使保留变差） |
| T2same − S1p | +0.0031 [0.0030, 0.0032] | −0.0007 [−0.0008, −0.0007] | 两组结构（同 λ=0.9、学习路由）相对单组，维度相同；效果随层变化，层 7 为负 |
| **T2L − T2same** | **+0.0049 [0.0047, 0.0051]** | **+0.0075 [0.0067, 0.0082]** | **时间尺度分离本身的效果**（结构、维度、路由都相同，只差 λ） |

解读（⚠️ 条件成立）：
1. 在去掉投影和结构的混杂之后，**时间尺度分离**在两层上都带来正的保留增益，且区间都不含 0。这是目前支持"快慢时间尺度本身有用"的最直接证据。
2. 只把记忆分成两组（同样的 λ）并不稳定地有用：层 3 为正，层 7 为负。
3. PCA-512 投影有一定成本（约 0.001–0.002）。因此 G4-a 中 T2L 优于 S1，实际上是在承受投影损失的情况下仍然更好。
4. 上述仍然只是离线、零样本、单一数据集、单一学习划分的结果。λ 位于网格边界，效果也很小。

## 7. H11b 方案 A：调参集上的扩展网格（仅调参集，不作为 G4 判定；`tune_grid_ext.py`，`results_tune_ext/`）

网格：λ_f ∈ {0.05, 0.1, 0.2, 0.3}，λ_s ∈ {0.8, 0.9, 0.95}（12 组）。差值为 T2L − S1 在调参集上的保留 AUC 均值。

- 两层平均的最优：**λ_f = 0.3，λ_s = 0.8**（+0.0077），仍在 λ_s 的下端点（边界），即 λ_s 可能还需更小。
- 层 3 的最优在 λ_f = 0.2、λ_s = 0.8（+0.0097）。
- 层 7 的最优在 λ_f = 0.3（扩展网格的上端，与原网格相同），λ_s = 0.8。层 7 在 λ_f 很小时明显为负（λ_f = 0.05 时约 −0.015），即快组过快会伤害层 7。

解读：
1. 边界问题只部分解决：λ_s 仍在下端点，λ_f 在两层上的最优不同（层 3 偏 0.2，层 7 偏 0.3）。
2. 相比原锁定值 (0.3, 0.95)，调参集上 (0.3, 0.8) 更好。但 G4 的测试集判定仍基于 (0.3, 0.95)，这一点不改变。
3. 若要据此改用新的 λ，必须通过方案 B（新的留出划分）判定，不能直接在测试集上使用。
