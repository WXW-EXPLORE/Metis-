# E014：1b 步骤一，接入回归测试与逐条验证记录

## 1. 回归测试（已通过）

脚本：`run.py`。结果：`result.json`。

在真实 Metis-4B 上，对同一个验证 episode 做三次前向：
原版 → 安装 RLS → 卸载 RLS → 原版。

| 检查 | 结果 |
|---|---|
| 卸载后 logits 与原版逐位相等 | 通过（最大差 0.0） |
| 卸载后 8 层记忆状态与原版逐位相等 | 通过 |
| 卸载后残留的实例级方法 | 无 |

说明：设计 1b §10 要求"新结构关闭时与原版逐位一致"。本测试验证的是"安装后卸载"能完全恢复原版行为。
RLS 的代码路径只在安装后生效，因此原版路径不受影响。
