# RLS 结果（修复前，已作废）

- rls_s0：完成，但使用的是未设置协方差上界、求逆在 fp32 下进行的代码。
- rls_s1：第 102 步崩溃，报错 `linalg.inv: ... the input matrix is singular`。

诊断：模拟显示，在遗忘因子 λ=0.9 下，未被激励的方向上协方差的迹从 $10^6$ 增长到 $8\times10^8$（最大特征值 $1.5\times10^7$）。这是设计 0a §10.3 预先写明的 windup 风险。

修复：在块更新中加入迹上界 $P_{\max}=kv^2$（设计 0a §10.3），并把求逆改为 float64。单元测试验证迹有界、300 步不崩溃。

处理：三个 RLS 种子全部用修复后的代码重跑。本目录内容不作为结论使用。
