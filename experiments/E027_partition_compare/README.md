# E027：分库比较（路由中心的划分相似度）

脚本：`compare.py`。结果：`partition_compare.json`。不重新运行模型，只比较已保存的路由中心。

**方法**：对两组中心（各 K=4，单位向量），枚举 24 种库编号排列，取使匹配后余弦最大的排列。匹配余弦接近 1 表示两组中心是同一划分（只差库编号）；越低表示划分越不同。对 8 个记忆层取均值。

| 比较 | 匹配余弦（层均值） | 最小值 | 解读 |
|---|---|---|---|
| CL_abs(s) vs CL_orig(s)，同一种子 | 0.983 | 0.891 | 读出形式改变后，学到的划分几乎不变 |
| CL_abs(0) vs CL_abs(1)，CL_abs(0) vs CL_abs(2)，CL_abs(1) vs CL_abs(2) | 1.000 | 1.000 | **三个种子学到的是同一划分** |
| RND_abs(0) vs RND_abs(1)，RND_abs(0) vs RND_abs(2)，RND_abs(1) vs RND_abs(2) | 0.029–0.097 | 负值 | 随机中心在种子间彼此独立，划分各不相同 |
| CL_abs(s) vs RND_abs(s)，同一种子 | 0.030–0.068 | 负值 | 学到的划分与随机划分几乎正交 |

## 结论（✅ 对所用的中心）

1. 竞争学习的原型对种子不敏感：三个种子收敛到同一划分。这意味着 E025 的 K4_CL 三个种子、E026 的 K4 三个种子都不是独立的划分样本（与 N15 更新一致）。
2. 随机中心在种子间是独立的，所以"随机分库"的三个种子是真实的独立重复。
3. 学到的划分与随机划分明显不同，因此 E025 中 K4_CL 与 K4_random 的比较确实在比较两种不同的划分。
4. 读出形式（`orig` 与 `abs`）只轻微改变了学到的划分（同种子匹配余弦 0.983）。

## 局限

- 比较基于中心的余弦，不是基于键的实际分配。匹配余弦为 1 说明中心一致，因此分配几乎一致，但没有在键上逐个验证。
- 竞争学习的种子只改变初始化。数据顺序是固定的，因此学到的划分在本数据上近似唯一。要得到独立的学习划分，需要改变数据顺序（例如打乱键的顺序）或改变学习率，这属于新的实验设计，需要单独登记。
