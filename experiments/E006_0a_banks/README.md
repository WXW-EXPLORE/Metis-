# E006：0a 参考记忆模块的验证

设计：`docs/design_0a.md`。实现：`src/holistic/banked_memory.py`（17 项单元测试通过，`tests/test_banked_memory.py`）。负结果：`docs/negative_results.md` N1–N5。

复现（仓库根目录）：

```bash
PYTHONPATH=src python experiments/E006_0a_banks/run.py --out experiments/E006_0a_banks
```

文件：`raw.csv`（逐条结果）、`summary.csv`（均值与标准差，5 个种子）、`config.json`。

## 设置

- **基线**：Metis 的 GDN 形式（K=1，β=1，带按键擦除），与 E001 的参考形式不同，两者数值**不可直接比较**。
- **臂**：K1（基线）；i（K=4，$d_b=d/4$，总状态与基线相同，等参数主比较）；ii（K=4，$d_b=d$，总状态为基线的 4 倍，仅作参考）。
- **路由**：softmax（τ=1）或 top-1。中心为**固定随机向量，未训练**。
- **维度**：$d=d_v=64$；5 个种子。

## 结果

### M1：分库与路由的串扰（目标读出余弦，越高越好）

| 配置 | ρ | n=32 | n=128 | 最大库利用率 | 路由熵 |
|---|---|---|---|---|---|
| K1（基线） | 0.0 | 1.000 | 1.000 | 1.00 | 0 |
| K1 | 0.1 | 0.751 | 0.197 | 1.00 | 0 |
| K1 | 0.3 | −0.010 | 0.102 | 1.00 | 0 |
| i（softmax） | 0.0 | 0.702 | 0.039 | 0.26 | 1.38 |
| i（top-1） | 0.0 | 0.659 | 0.079 | 0.30 | 0 |
| i（top-1） | 0.3 | 0.268 | −0.025 | 0.42 | 0 |
| i（top-1） | 0.6 | −0.057 | 0.039 | 0.59 | 0 |
| ii（softmax，参考） | 0.1 | 0.816 | 0.374 | 0.25 | 1.38 |

观察（已验证的数值，机制解释见负结果）：

1. **臂 i 在 ρ=0 时召回大幅下降**（n=128 时 0.04–0.08，基线为 1.00）。这是随机投影破坏键正交性造成的（N1），不是分库的收益。
2. **softmax 路由几乎均匀**（熵 1.38，接近最大值 $\log 4$），分库没有实际发生（N2）。
3. **top-1 分库在 n=32、ρ=0.3 时优于基线**（0.268 对 −0.010）。这是分库的正面证据，但只在这一个点上，且 ρ=0 时被投影的损失抵消。
4. **相关键导致路由塌缩**：top-1 时 ρ 从 0 增至 0.6，最大库利用率从 0.30 升到 0.59（N4）。

### M2：多时间尺度的年龄曲线（目标读出余弦）

| 配置 | age=4 | age=16 | age=64 | age=256 |
|---|---|---|---|---|
| 单库 α=0.9 | 0.968 | 0.538 | 0.007 | −0.022 |
| 单库 α=0.99 | 0.982 | 0.859 | 0.299 | −0.002 |
| 单库 α=0.999 | 0.983 | 0.877 | 0.404 | 0.138 |
| 快慢两库（0.9, 0.999），top-1 | 0.982 | 0.801 | 0.240 | 0.055 |

观察：

- 单库遗忘率越小，信息保持越久，符合预期。
- **快慢两库在未训练的路由下未优于单库 α=0.999**（age=64 时 0.24 对 0.40）（N5）。多时间尺度的收益依赖路由能学到正确的分配，0a 无法单独证实。

### M3：显式删除的误伤与残留（n=32）

| 配置 | ρ | 误伤（越低越好） | 目标残留（越低越好） |
|---|---|---|---|
| K1 | 0.1 | 0.218 | $10^{-15}$ |
| K1 | 0.6 | 0.968 | $10^{-15}$ |
| i（softmax） | 0.1 | 0.040 | 0.803 |
| i（softmax） | 0.6 | 0.136 | 0.989 |
| i（top-1） | 0.1 | 0.066 | $10^{-15}$ |
| i（top-1） | 0.6 | 0.477 | $10^{-15}$ |

观察：

1. **基线的误伤随 ρ 急剧增大**（0.22 → 0.97），与 E001 的趋势一致。
2. **top-1 分库把误伤降到约一半**（ρ=0.6 时 0.48 对 0.97）。
3. **软路由下删除不完整**：目标残留 0.80–0.99（N3）。这一结果不能当作"误伤小"，因为目标本身没有被删掉。

## 限制

1. **路由中心未训练。** 0a 中的路由是固定随机分配。学到的路由可能明显不同，M1、M2 的分库结论只对固定随机路由成立。
2. **只用随机高斯值。** 语义数据中的值相关性未考虑。
3. **单个 α 配置网格。** M2 只测了少数 α 组合。
4. **臂 i 的结果受投影影响**（N1），不能单独归因于"分库"。
5. 实验中的键由构造得到，ρ 是设定值。

## 对设计的含义（需在训练前确定）

这些发现直接影响"后期训练不推翻"的目标。以下三点需要在设计 A、C、E 中明确，否则训练后的参数会建立在错误的语义上：

1. **库内键表示**：随机投影 $P_b$ 不能用于等参数分库（N1）。候选方案需要单独设计并验证。
2. **路由**：softmax 的温度或学习方式必须规定。软路由不分库（N2）；硬路由需要负载均衡（N4）。
3. **删除与写入使用同一路由**：否则删除不完整（N3）。

在这三点确定前，不建议继续实现 0a 的 C（显式删除）和 D（解耦）。
