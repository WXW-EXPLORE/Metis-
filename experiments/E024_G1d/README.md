# E024 / G1d：数据自适应路由在真实对话键上的检验

- 设计：`docs/design_G1d.md`（判据于运行前登记，运行后未修改）
- 脚本：`run.py`；结果：`result.json`；日志：`/hy-tmp/metis-outputs/E024.log`
- 数据：LoCoMo 记忆步骤，按对话拆分（前 5 个对话拟合，后 5 个对话的前 30 个会话测试）
- 规模：fit 273 个会话，test 30 个会话（30 个 episode）；等总状态 4×256×1024；3 个种子

## 观察（非判定）

1. 真实键上，等总状态的路由原型没有超过单库。层 3 的差距很小但显著为负，层 7 的差距较大（−0.011）。
2. CL_cons 与 K4_random 基本持平（层 3 −0.0005，层 7 +0.0004）。G1d-c 的通过主要反映 balanced_free 基线较弱（它甚至低于随机分配），而不是内容路由本身的收益。
3. 负载：CL_cons 在层 7 的最大库占比为 0.30，比层 3 的 0.44 均衡。与 G1c 不同，这里层 3 的负载并不稳定。
4. **种子的局限**：CL 各臂的最大库占比在 3 个种子之间完全相同（如 K4_CL_cons 层 3 均为 0.4382），而原型初始化确实使用了种子。这说明 3 个种子可能只产生了近乎相同的分配，"3 个种子"的方差估计可能偏低。需要单独检验（见下一步）。

## 限制

- 只有 5 vs 5 个对话，30 个测试 episode。
- 自检索指标，不是问答正确率。
- 同一对话内的会话可能相关；按对话拆分已减轻，但未消除。
