# 设计说明：R0 — 合成数据上的规律子空间形成（数学与数值检验）

状态：判据预先登记于本文件，运行前不修改。日期：2026-10-21。
依据：`docs/theory_regularity.md`（快速存储 → 跨库交互 → 慢速规律形成；约束已按 2026-10-21 调整为"线性载体 + 非线性组织"）。
范围：纯数值模拟，不涉及 Metis 模型。快库的存储（R1）不在本阶段。

## 1. 要检验什么

慢速规律子空间 U 能否从经历中稳定地形成，并对未见过的同类经历泛化；且这一收益不是来自容量或平均。

## 2. 数据（结构已知）

- 环境维度 d = 64；潜在因子数 m = 4。
- 经历 x = A z + ε，其中 z ~ N(0, diag(σ²))，σ = (3, 2, 1.5, 1)；A ∈ R^{64×4} 为随机正交列（列正交化后）；ε ~ N(0, 0.3² I)。
- 真实规律子空间 U* = A 的列（正交基）。谱隙：σ 之间有明显间隔。
- **无规律对照**：x ~ N(0, I_64)（各向同性，无共同方向）。
- 每个随机种子独立生成 A、训练集与测试集。

## 3. 学习规则（慢速，只作用于 U）

- 初始化：U_0 为随机正交 64×4 矩阵。
- Oja 子空间规则（带 QR 回缩）：对每个经历 x，编码 c = Uᵀx，更新 U ← qr(U + η x cᵀ)（取 Q 因子，并使对角符号为正）。
- 学习率 η = 0.01（固定）；训练经历数 N_train = 5000 每个种子；经历依次输入（单次遍历）。
- 快库与残差存储不在本阶段讨论。

## 4. 度量

- **重建误差（泛化，T1）**：测试集（新的同分布经历，N_test = 2000）上 E‖x − U Uᵀ x‖² / E‖x‖²。
- 基线：
  - 随机 U（未学习，同一初始化）；
  - 神谕 U*（真实规律，上界）。
- **主子空间夹角**：U 与 U* 的最大主角余弦（越接近 1 越对齐）。
- **漂移（T3）**：在学习后的 U 上继续输入 N_drift = 5000 个无规律经历（x ~ N(0, I)），测量 U 的漂移（最大主角）。

## 5. 判据（运行前登记）

- **T1 泛化**：对 20 个种子，逐种子配对差 D = 重建误差(随机 U) − 重建误差(学习的 U)。要求 D 的 bootstrap 95% 区间下界 > 0，且学习的 U 相对随机 U 的误差降低达到神谕降低的 50% 以上（按种子均值）。
- **T2 无规律对照**：在无规律数据上训练，D_null = 重建误差(随机 U) − 重建误差(学习的 U)。要求 D_null 的 95% 区间包含 0（即无收益），且其绝对值小于 T1 的 D 均值的 25%。
- **T3 稳定性**：有规律情形下，无规律漂移经历后的最大主角余弦 ≥ 0.95（漂移有界）。
- **T4 形成过程**：训练经历数 N ∈ {100, 500, 1000, 2000, 5000}，最大主角余弦随 N 单调（或近似单调）增加，且 N=5000 时 ≥ 0.95。

R0 通过 = T1、T2、T3、T4 全部满足。任一不满足则记录为负结果，不修改判据。

## 6. 多种子与报告

- 20 个种子，报告均值与标准差；逐种子配对差与 bootstrap 区间。
- 谱隙检查：报告 σ_4² 与 σ_5 对应的理论谱隙（此处 σ_5 = 0，因此每个种子另报告样本协方差的第 4、5 特征值比）。

## 7. 失效模式

- **谱隙不足 / 学习率过大**：U 不收敛或振荡（T4 失败）。
- **无规律数据仍有收益**：说明收益来自平均或容量（T2 失败），此时不能称为"规律形成"。
- **漂移过大**：规律不稳定（T3 失败）。

## 8. 与主线其他部分的关系

- R0 通过只说明：在结构已知的数据上，慢速规则能形成规律子空间。它不能证明真实模型中存在规律（那是 R2 的任务）。

## 9. 结果（2026-10-22，20 个种子，`experiments/R0_regularity/results/summary.json`）

| 判据 | 结果 | 判定 |
|---|---|---|
| T1 泛化 | D = 0.673，95% 区间 [0.664, 0.682]，占神谕间隙 97.5% | 通过 |
| T2 无规律对照 | D_null = 0.0001，区间 [−0.0003, 0.0007] | 通过 |
| T3 稳定性 | 无关经历后最大主角余弦均值 0.036（要求 ≥ 0.95） | **未通过** |
| T4 形成过程 | N=5000 时 0.9825 ≥ 0.95（满足）；但曲线在 N=2000→5000 有 0.0005 下降，违反严格单调 | **未通过**（见下） |

- T4 的单调性：设计写的是"单调（或近似单调）"，实现时我用了严格单调，这是实现疏漏。0.0005 的下降是否属于"近似单调"，需要在下一轮预先登记容差后再判定，本轮不改判。
- 解读：慢速规则能形成规律子空间（T1、T2），但固定学习率下它对无关经历不稳定（T3），规律会被冲掉。慢速部分的时间尺度必须与经历速率真正分离。
- 下一步（R0b，需预先登记）：以 η 随时间衰减（例如 η_t = c/t）或加入遗忘/收缩项，检验 T3 与 T1 能否同时满足，并明确 T4 的容差。
