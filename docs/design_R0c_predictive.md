# 设计草案：R0c — 时间序列上的预测规律（同边际协方差、不同动态的对照）

状态：**已确认**（2026-10-22）。确认事项：先用线性高斯模型，效果不足时回到 CLAUDE.md 第 7 条重新评估；两个转移矩阵谱相同；阈值同意；范围已扩展（CLAUDE.md 第 7 条）。日期：2026-10-22。
依据：`docs/theory_innovations.md`（§0 指出 R0 为 i.i.d. 数据，只检验边际协方差；§5 给出本对照的理论依据）。
范围说明：本设计检验"预测规律是否可被辨识、且是否优于纯边际统计"。不涉及快层存储（留给 R1），不涉及因果干预（留给 R3）。

## 1. 要检验什么

在**同一边际协方差**的两个过程之间，只有使用时间上的交叉统计量的学习器，才能学到其动态规律。
- 若这一点成立，说明"规律"需要的统计量与"压缩协方差"不同，R0 的子空间方法在结构上无法学到动态规律。
- 若不成立（两种学习器表现相同），说明在该设定下边际统计已足够，对照无效，需要改设定。

## 2. 数据（线性高斯，状态即观测，结构已知）

- 维度 d = 4；稳定转移矩阵 A_1、A_2（谱半径 < 1，见下）。
- 目标边际协方差 Σ = I_4（固定）。
- 对每个 A，取噪声协方差 Q_A = Σ − A Σ Aᵀ（需半正定，因此只选满足该条件的 A）。
- 过程：s_{t+1} = A s_t + w_t，w_t ~ N(0, Q_A)，观测 x_t = s_t。
- 则两个过程的边际分布都是 N(0, Σ)：**边际协方差相同，动态不同**。
- 动态差异由 A 决定：lag-1 交叉协方差 E[x_{t+1} x_tᵀ] = A Σ，不同 A 给出不同的时间依赖。

选择两个 A：
- A_1 = 0.9 · R_1，A_2 = 0.9 · R_2，其中 R_1、R_2 为随机正交矩阵的某种组合，使 A_1 与 A_2 的特征值一致（或者不一致，待确定）。**这一选择需要确认**（见第 7 节）。

## 3. 学习器

- **L0（边际学习器）**：只使用 x 的样本协方差 Σ̂_0。预测器：x̂_{t+1} = 0（或均值）。它不包含任何时间信息。
- **L1（交叉协方差学习器）**：使用 Σ̂_1 = Ê[x_{t+1} x_tᵀ]，估计 Â = Σ̂_1 Σ̂_0^{-1}，预测器 x̂_{t+1} = Â x_t。
- **Oracle**：真实 A，上界。

L0 与 L1 的差异仅在于使用的统计量：L0 只看边际，L1 看一阶时间交叉。两者都是线性的、闭式的，不涉及迭代学习，因此这个对照只检验统计量选择。

## 4. 度量

- 一步预测误差（归一化）：NMSE = E‖x_{t+1} − x̂_{t+1}‖² / E‖x_{t+1}‖²，在独立测试序列上计算。
- 预测增益：G = NMSE(L0) − NMSE(L1)。
- 可辨识性：NMSE(L1) 随训练长度 N 的变化，以及 Â 与 A 的误差。

## 5. 判据（草案，运行前登记）

- **P1（同边际）**：L0 与"朴素零预测"的 NMSE 差 ≈ 0（95% 区间包含 0）。这验证边际统计不含预测信息。
- **P2（时间统计量有信息）**：G 的 95% 区间下界 > 0，对所有 A 成立（或对预先登记的 A 集合成立）。
- **P3（可辨识）**：NMSE(L1) 随 N 单调下降，且 N 足够大时接近 Oracle（相对差 < 5%，需确认阈值）。
- **P4（稳定性前提）**：只对谱半径 < 1 的 A 进行检验。

通过 = P1、P2、P3、P4 全部满足。

## 6. 失效模式

- 两个 A 的动态差异太小：G 接近 0，对照无效，应增大差异（改设定，而非改判据）。
- Σ̂_0 病态（样本少）：L1 不稳定，需报告条件数。
- 若 L0 也能预测（P1 失败）：说明边际与动态不可分，设定不成立。

## 7. 需要你确认的决定

1. **数据类型**：是否先用线性高斯 SSM（有完整理论，但只是线性情形），还是直接使用非线性或切换动态（更接近"规律"，但理论较弱）。我倾向先线性。
2. **A 的选择**：两个 A 的谱是否相同（只差特征向量，更严格的对照）还是不同（更直观）。我倾向使特征值相同、特征向量不同，这样边际之外的差异只来自时间结构。
3. **阈值**：P2 的 G 阈值（区间下界 > 0）与 P3 的相对差（< 5%）是否合适。
4. **范围**：本设计属于"预测规律与创新"，超出 `CLAUDE.md` 研究侧重点的六个方向。需要先决定是否扩展范围并更新 `CLAUDE.md`，否则只能停留在文档层面。

## 8. 与既有结果的关系

- 本设计检验的是 R0 缺失的那一部分：时间结构。它不替代 R0，而是补充。
