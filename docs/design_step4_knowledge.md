# 设计草案：第 4 步 — 知识的操作性检验（泛化、干预、原始经历屏蔽）

状态：**草案，待用户确认后运行**。日期：2026-10-22。
依据：收窄主线第 4 步；`docs/theory_innovations.md` §1（预测充分统计量）与 §4（预测相关与因果规律的区分）。
前置：R0c（线性预测规律可辨识）、R1（分工有收益，R1-d′ 通过）、第 3 步（版本一致性，L=50）。

## 1. 要检验什么

学到的慢层表示，是否只是观测层面的统计关联，还是反映了潜在结构。三个可操作的检验：

- **K-A 泛化**：对未见过的同分布经历，学到的表示能否准确预测/重建。
- **K-B 不变性**：对与潜在结构无关的扰动（例如观测噪声的水平、与状态无关的通道），表示保持稳定。
- **K-C 干预敏感性**：当潜在结构被干预（改变潜在因子，而不是改变观测的统计相关）时，表示的预测应相应改变。

## 2. 关键设定：观测相关与潜在干预的区分

线性模型中，观测层的一步预测器 M 学到的是观测的统计关联：x̂_t = M x_{t−1}。它把 x_{t−1} 当作状态的代理。

- 若干预只改变 x_{t−1}（不改变潜在状态 s_{t−1}），真实的未来 x_t 不变（它由 s_t 决定）。观测预测器会错误地改变预测。
- 若干预改变潜在状态 s，真实的未来会按动态改变，结构化预测器应跟随。

因此 K-C 的判别量是：**在"只干预观测、不改变潜在状态"的情形下，预测器是否错误地跟随干预。** 这是"统计关联 vs 结构"的直接检验，也正是 P1 所指的问题。

## 3. 数据（线性高斯，结构已知，延续 R1）

- 状态 s（m=4），观测 x = C s + v（d=8，R=0.5），s 的动态 A（谱半径 0.9，与 R0c 相同）。
- 训练序列：N=20000（R1b′ 的设定）；测试序列：独立生成。
- 结构化预测器（oracle，仅作参照）：卡尔曼滤波给出的 x̂_{t|t-1}（使用真实 A、C、R，只看历史）。

## 4. 臂

- **O（观测预测器）**：慢层学到的 M（R1b′ 的 LMS 学习，同设定）。
- **S（结构预测器）**：卡尔曼预测（oracle 参数）。
- **Base（零预测）**：x̂ = 0。

## 5. 度量

- **K-A**：测试集上的一步预测 NMSE（新 episode，同分布）。
- **K-B**：观测噪声 R 变化（例如 R ∈ {0.5, 1.0}，训练在 R=0.5，测试在 R=1.0）后的 NMSE 变化。
- **K-C**：干预实验。对测试序列的每个时刻 t，把 x_{t−1} 替换为从边际分布独立抽取的值（do，只改观测），保持 s_{t−1} 和后续噪声不变。计算 x_t 的真实值与各预测器的预测之差：
  - 干预后的误差增量 Δ = NMSE(干预) − NMSE(未干预)。

## 6. 判据（运行前登记，草案）

- **K-A**：O 的 NMSE 低于 Base，且与 S 的相对差 < 10%（泛化到新 episode）。
- **K-B**：O 在 R 变化后的 NMSE 增量 ≤ 1.5 × S 的增量（不变性不显著差于结构预测器）。
- **K-C**：O 的 Δ 显著大于 S 的 Δ（区间下界 > 0）。这表示观测预测器错误地跟随了观测干预，而结构预测器没有。
- 通过 = K-A、K-B、K-C 全部满足。

**解释规则**：若 K-C 不成立（O 与 S 对干预同样不敏感），说明在该设定下观测预测器已经接近结构预测器，干预检验无区分力，需要重新设计干预，而不是修改判据。

## 7. 需要确认的决定

1. **干预的定义**：只干预观测（do(x_{t−1})，保持潜在状态），是否符合你对"因果干预"的理解。还是也需要干预潜在因子（直接改变 s）的版本？我倾向两者都做，因为后者是 K-C 的正面检验。
2. **K-B 的扰动**：只改变观测噪声 R，是否足够代表"与结构无关的扰动"。
3. **结构预测器的地位**：S 使用真实参数（oracle）。这与前面 R1 的 oracle 设定一致，但意味着 K-C 的结论是"可实现的结构预测器上界"，而不是学习到的结构。是否接受。
4. **判据阈值**：K-A 的 10%、K-B 的 1.5 倍，是否合适。

## 8. 修订（2026-10-22，用户确认）

- **干预**（§7-1）：接受。两种都做：只干预观测（do(x_{t−1})），以及直接改变潜在状态（do(s)）。
- **K-B 扰动**（§7-2）：需要实验排除。改为用预试验比较候选扰动，选出"对结构预测器影响小、但对观测预测器有影响"的扰动，并用一个结构性改变（转移矩阵缩放）作为正对照，确认检验有区分力。
- **结构预测器**（§7-3）：接受 oracle 设定，结论为上界。
- **阈值**（§7-4）：不由设计者指定，改为预试验校准：
  - K-A 阈值：取"好的观测预测器"与"故意劣化的预测器（M×0.5）"之间的几何中点，使阈值能区分两者。
  - K-B 倍数：同样用正对照校准。
  - K-C：不设数值阈值，只用 Δ_O − Δ_S 的 95% 区间下界 > 0。

**预试验**（`experiments/step4_knowledge/pilot.py`，种子 900–902，与正式实验分开）只用于选择上述数值，不用于判定。

## 9. 预试验结果与登记的判据（2026-10-22，种子 900–902，`experiments/step4_knowledge/pilot*.py`）

- **K-A 校准**：O 比 S 高 7.1%；劣化预测器（M×0.5）比 S 高 16.6%。几何中点约 11.8%。**登记：K-A 阈值 = 11.8%（相对 S 的 NMSE 差）。**
- **K-B 扰动校准**：
  - 噪声 ×2（不重新适应旧模型）：ΔS = 0.126，ΔO = 0.138，差 0.012。
  - 结构正对照（转移 ×0.95）：ΔS = 0.022，ΔO = 0.010。O 退化更少。
  - 结论：比值形式的 K-B 判据（ΔO ≤ 1.5 ΔS）**对结构改变没有区分力**，且本设定没有合适的"不变性失败"正对照。**登记：K-B 改为绝对判据：噪声 ×2 下 ΔO − ΔS ≤ 0.02**（约等于预试验的噪声扰动差，并如实注明没有正对照）。
- **K-C 校准**：do(x_{t−1})（只改观测，潜在状态不变）下，ΔO = 0.436（sd 0.012）；结构预测器 ΔS = 0（按因果定义忽略被干预观测）。区分力强。**登记：K-C 判据 = Δ_O − Δ_S 的 95% 区间下界 > 0。**
- **do(s)**（潜在状态干预）：仅报告，不作判定。

**注意**：K-B 的校准不如 K-A、K-C 可靠，结论需要在报告中注明。

## 10. 正式结果（2026-10-22，种子 0–19，`experiments/step4_knowledge/results/summary.json`）

| 判据 | 结果 | 判定 |
|---|---|---|
| K-A 泛化（O 相对 S 的 NMSE 差 ≤ 11.8%） | 平均 7.6% | 通过 |
| K-B 不变性（噪声 ×2 下 ΔO − ΔS ≤ 0.02） | 0.0085、0.0072、0.0098（区间均在阈值内） | 通过（**无正对照**，见下） |
| K-C 干预（Δ_O − Δ_S 的 95% 区间下界 > 0） | 0.449，区间 [0.443, 0.455] | 通过 |

**注意与局限**：
- K-C 的结构预测器 Δ_S = 0 是由定义给出的（它忽略被干预的观测），因此 K-C 检验的是"观测代理 vs 潜在结构"，不是学习到的结构。
- K-B 没有正对照，只能说明观测预测器与结构预测器在噪声扰动下表现相当，不能说明它能识别不变性失败。
- **do(s) 的报告数字无效**：实现中只替换了观测序列，没有重新生成真实的 x_t，目标与干预不一致。该数字不用于任何结论，需要修正后重跑（不属于本次判定）。

**结论**：在线性高斯设定下，观测预测器对观测层干预的错误跟随（K-C）可以被检出，并且观测预测器的泛化接近结构预测器（K-A）。这支持"学到的表示依赖观测代理，而非潜在结构"的诊断，但仅限于本设定；它不证明慢层学到了可干预的潜在结构。

## 11. do(s) 修正后的报告（2026-10-22，不判定，`experiments/step4_knowledge/run_do_s.py`，种子 0–19）
