# 设计说明：G1d，数据自适应路由在真实对话键上的检验（等总状态）

状态：已确认（用户，2026-10-16："确认"）。判据在运行前登记。
依据：G1c（E023，合成键上通过），E016（真实键低秩），E022（负载对随机中心敏感）。

## 1. 目的

G1c 的结论只对合成 episode 成立。G1d 检验同一机制（竞争学习 + 内稳态的路由原型）在真实对话的记忆步骤上是否仍然成立。

## 2. 数据

- 来源：LoCoMo 的记忆步骤（`eval/data/memqa/locomo_evidence_sessions_tps16_20260626.jsonl`，按会话去重，共约 568 个会话）。
- **只用于诊断**：LoCoMo 是评测数据，本实验不做训练，只检验路由的结构与性能，符合"不得修改评测集、指标或划分"的规则。
- 拆分：**按对话（10 个 sample_id）拆分**，前 5 个对话用于拟合原型与 PCA 基，后 5 个对话用于测试。这样测试键来自未见过的对话。
- 测试规模：为控制成本，测试取后 5 个对话中的前 30 个会话（若不足则全部）。

## 3. 臂与指标

与 G1c 完全相同：K1_full、K1_pca256、K4_random、K4_CL（β=0）、K4_CL_cons（β=1，主臂）、K4_balanced_free（内容无关均衡）。等总状态（4×256×1024）。
指标：自检索余弦（按 episode），配对 bootstrap 95%；负载按种子单独报告。

## 4. 判据（预先登记，两层分别判定，与 G1c 相同）

- G1d-a：K4_CL_cons 每个种子的最大库占比中位数 < 0.40。
- G1d-b：K4_CL_cons − K1_full 的区间下界 > 0。
- G1d-c：K4_CL_cons − K4_balanced_free 的区间下界 > 0。
- G1d 通过：三条同时满足，两层都满足。

另外报告 G1c 与 G1d 的差异（合成 vs 真实），不作为判定。

## 5. 限制

- 真实对话的记忆步骤是按会话和轮次切分的，与合成 chunk 长度分布不同（每步约 500 token）。
- 拆分只有 5 vs 5 个对话，测试会话数有限。
- 同一对话的会话之间可能有相关性；按对话拆分已减轻泄露，但未完全消除。
- 自检索指标，不是问答正确率。
