# 设计说明：E031 — 初始不匹配（B 的下一步，不训练）

日期：2026-10-25。状态：**运行前登记**。依据：`experiments/E029_gap_diagnosis/README.md` 的新观察（RLS 初始 NLL 9.43，GDN 7.28）。

## 1. 问题

初始 NLL 差距（2.15 nats）出现在训练之前。两种臂的记忆投影都被 `reinit_memory` 重新随机化，因此差距来自记忆结构本身，而不是预训练参数。需要回答两个问题：

1. RLS 的 9.43 是否等于"无记忆"地板？（若是，RLS 的初始记忆没有提供信息；若 GDN 低于地板，则 GDN 的记忆在初始化时就有用。）
2. RLS 的记忆分支是否过大，从而扰动骨干？（用 `last_memory_attention_norm_ratio` 度量。）

## 2. 方法

- 评测：pilot 划分的前 100 个 episode（与 E029 相同，测试集不读）。
- 不训练。每个变体复现 E025 训练脚本的初始化顺序（seed 10 → 加载 → 安装 → `reinit_memory`），并用 E029 P0/P3 的 step-0 数字做对照检查（9.4331 与 7.2830）。
- 变体（每个只改一处，相对 RLS 基线 R0）：

| 变体 | 臂 | 读出 | 读出乘子 s |
|---|---|---|---|
| G | GDN（原版） | — | 1 |
| R0 | RLS | abs | 1 |
| R-orig | RLS | orig | 1（单变量：分母） |
| Z-G | GDN | — | 0（读出置零 = 无记忆地板） |
| Z-R | RLS | abs | 0（同上） |
| S-R | RLS | abs | 0.1（幅度检验） |

读出置零通过包装 `local_memory.read` 实现（`read(q) * s`），其余路径不变。

- 记录：step-0 NLL（100 个 episode 的均值）；在边界记忆层上 `last_memory_attention_norm_ratio` 的均值。

## 3. 判据（预先写定）

- **地板判断**：若 |NLL(Z-R) − NLL(R0)| ≤ 0.1，则 RLS 初始记忆基本无信息（地板）。若 NLL(Z-G) − NLL(G) ≥ 0.5，则 GDN 的记忆在初始化时有用。
- **扰动判断**：若 NLL(S-R) < NLL(R0) − 0.5，说明 RLS 记忆分支幅度过大，扰动了骨干。
- 这些判据只用于决定下一步诊断方向，不作为"机制已确认"的依据。

## 4. 局限

- 仅初始化，不含训练动力学。
- 单种子（10）；初始化对种子敏感，结论只是方向性的。
- 比率只在边界层测量（由 `monitor_branch_norms` 决定）。

## 5. 失效模式与回滚

- 若复现的 step-0 数字与 E029 不一致（超过 0.01），先排查 RNG 顺序，不解释结果。
- 只写 `experiments/E031_init_mismatch/`，不修改 `src/` 或 `metis/`。

## 6. 结果（2026-10-25，pilot 前 100 个 episode，step-0，不训练）

数据：`experiments/E031_init_mismatch/runs/*.json`。

| 变体 | step-0 NLL | 记忆/注意力范数比（block 3 / block 31） |
|---|---|---|
| G（GDN） | 7.283 | 29.1 / 4.41 |
| R0（RLS，abs） | 9.434 | 37.6 / 6.34 |
| R-orig（RLS，orig 分母） | 9.010 | 37.9 / 6.35 |
| Z-G（GDN，读出置零） | 6.052 | 0 |
| Z-R（RLS，读出置零） | 6.052 | 0 |
| S-R（RLS，读出×0.1） | 9.434 | 37.6 / 6.34 |

**复现检查**：G 7.2834 对 E029 的 7.2830，R0 9.4337 对 9.4331。通过。

**判定**：
- 无记忆地板为 6.052（两臂相同，符合预期）。
- 地板判断：|Z-R − R0| = 3.38 > 0.1，RLS 初始记忆远非无信息，而是**有害**。
- GDN 的记忆在初始化时同样有害（Z-G − G = −1.23，不满足 ≥ 0.5 的"有用"判据）。
- 扰动判断（S-R < R0 − 0.5）**未满足**，但该检验本身无效（见下）。

**解读**：
- **已验证**：初始化时，两种记忆分支都远大于注意力分支（block 3 处 29–38 倍），并把 NLL 推高 1.2–3.4 nats。
- RLS 的比值比 GDN 高约 1.3 倍，与 NLL 差距同向，但我没有证明两者因果相关。
- orig 分母（R-orig）比 abs 分母低 0.42 nats，仍远高于地板。分母选择对初始化有影响，这与 E029 前的选择（abs，为梯度稳定）有张力，需要记录。
- **设计缺陷**：S-R 无效。读出乘 0.1 后 NLL 与比值几乎不变（9.4339 对 9.4337）。这说明记忆分支对读出的整体幅度不敏感，很可能是 `mem_norm`（归一化层）抵消了缩放。这一点是推测，未核实运行时的块类。因此"幅度过大"的假设尚未检验，不能据此排除。

**2026-10-26 修正（E032）**：已核实 `mem_norm` 为 `Qwen3_5RMSNorm`，对输入乘 0.1 的输出差为 0.031（输出最大值 8.56），即缩放被归一化抵消，S-R 的无效原因确认。另外两点修正：(a) 有效缩放实际为 2.0（见 §7），本表的所有运行都是在这个缩放下进行的；(b) 上表的比值是加权前的数值。块的融合为 `0.9·attn + 0.1·mem`（`metis_block.py`，`metis_reweight_gamma = 0.9`），因此有效的记忆/注意力比为 `(0.1/0.9)·ratio`：GDN 约 3.2，RLS 约 4.2（第 3 层）。仍大于 1，但远小于上表的 29–38 倍。

**结论等级**：已验证的结论是"初始化的记忆分支有害，两臂都是"。"RLS 的差距主要来自分支幅度"是猜想。

**下一步候选（需确认）**：
1. 把 `mem_norm_init`（配置项，默认 1.0，文档示例 0.2）对两臂同时降低，检验初始有害是否可以消除。这是单变量改动，但会改变训练协议，需要先登记。
2. 核实 `mem_norm` 的实际位置（运行时的块类与 RMSNorm），再重做 S-R。

## 7. 运行前登记：E031b（mem_norm 缩放，只看初始化，不训练）

日期：2026-10-26。依据：E032 发现两个实现问题。

1. **mem_norm 的类是 `Qwen3_5RMSNorm`，前向为 `x̂ · (1 + weight)`**（`transformers/models/qwen3_5/modeling_qwen3_5.py`）。因此有效缩放为 `1 + weight`，不是 `weight`。
2. `E013/train.py::reinit_memory` 把 `mem_norm.weight` 设为 **1.0**，所以有效缩放为 **2.0**。`metis_block.py` 中 `mem_norm_init` 的代码是直接 `fill_(init_val)`，对这个 RMSNorm 而言，配置 `0.2` 的有效缩放是 1.2，而不是 0.2。

**影响**：E013、E025、E029、E031 的所有记忆分支幅度都是按缩放 2.0 计算的。两臂受同样影响，因此配对比较仍然有效，但绝对数值和记忆分支比值（E031 §6）需要修正。`mem_norm_init` 的语义在这个 RMSNorm 上是错的。

**本次不修改训练代码，也不重跑训练。** 只在初始化时检验缩放的效果。

变体（两臂，种子 10，pilot 前 100 个 episode，step-0）：

| 变体 | 臂 | 有效缩放（1+weight） | 设置 |
|---|---|---|---|
| S1-G / S1-R | GDN / RLS | 1.0 | weight = 0（Qwen 原始零初始化） |
| S02-G / S02-R | GDN / RLS | 0.2 | weight = −0.8 |

判据（登记）：
- 若 S1 的初始有害（NLL − 地板）比缩放 2.0 小一半以上，则说明缩放是初始有害的主要来源之一。
- 若 S02 与 S1 差别小于 0.1，则说明初始有害对缩放不敏感。
- 这些判据只决定下一步是否登记训练实验，不作为结论。

**局限**：只看初始化；单种子；缩放改动会改变训练协议，若要采用需另行登记。

## 8. 结果：E031b（mem_norm 有效缩放，step-0，pilot 前 100 个 episode，不训练）

数据：`experiments/E031_init_mismatch/runs/{S1,S02}_{G,R}.json`。地板（读出置零）= 6.052。

| 有效缩放 (1+weight) | GDN NLL | GDN 超出地板 | RLS NLL | RLS 超出地板 | RLS − GDN | 记忆/注意力比（第 3 层，加权前） |
|---|---|---|---|---|---|---|
| 2.0（训练中实际使用，weight=1） | 7.283 | +1.231 | 9.434 | +3.382 | 2.151 | GDN 29.1 / RLS 37.6 |
| 1.0（Qwen 原始，weight=0） | 5.739 | −0.313 | 6.201 | +0.149 | 0.462 | GDN 14.6 / RLS 18.8 |
| 0.2（weight=−0.8） | 6.089 | +0.037 | 6.032 | −0.020 | −0.057 | GDN 2.9 / RLS 3.7 |

**判定（按 §7 登记的判据）**：
- 判据 1 满足：缩放 1.0 的初始有害量远小于缩放 2.0（GDN 由 +1.23 变为 −0.31；RLS 由 +3.38 变为 +0.15）。
- 判据 2 不满足：缩放 0.2 与 1.0 的差在 GDN 为 0.35、在 RLS 为 0.17，均不小于 0.1。

**解读**：
- ✅ 已验证：有效缩放 2.0 是初始有害的主要来源。在缩放 1.0 下，GDN 的记忆在初始化时**低于地板**，即有帮助，RLS 仅轻微有害（+0.15）。
- ✅ 已验证：两臂在初始化时的差距由 2.15 缩小到 0.46（缩放 2.0 → 1.0），约缩小 4.7 倍。
- ⚠️ **更重要的后果**：E013、E025、E029、E031 的所有训练与初始化都使用缩放 2.0（reinit_memory 的 `fill_(1.0)` 造成）。训练后的差距（D ≈ +0.28 至 +0.34，E025 的 G1e 比较）可能会随缩放改变，需要在缩放 1.0 下重新检验。这是猜想，尚未检验。
- 判据 2 不满足说明：在缩放 0.2 到 1.0 之间，初始 NLL 仍对缩放敏感，因此不能只用一个缩放值下的结论。
- 有效（经 γ = 0.9 加权后）的记忆/注意力比在缩放 1.0 下约为 GDN 1.6、RLS 2.1，仍大于 1 但远低于缩放 2.0 时的 3.2、4.2。

**结论等级**：初始化效应已验证（单种子 10，step-0）。训练后的影响未检验。

**需要的决定**（不在本登记内执行）：
1. 是否修正 `reinit_memory`（把 `mem_norm` 恢复为 Qwen 原始零初始化，或显式设为缩放 1.0），并在修正后重新检验训练。这会改变训练协议，E013–E031 的绝对数值都需要标注为"缩放 2.0"。
2. 若同意，建议先做 pilot 训练（P0 与 P3，缩放 1.0，种子 10，约 1 小时），检验训练后的 GDN − RLS 差距是否仍然存在。正式比较需另行登记。
