# 主线锚点（每一步局部工作前后都要对照）

## 最终目标
得出一个在相同参数与状态预算下，**优于原版 Metis 记忆（GDN）** 的记忆机制设计。衡量对象是下游任务（LoCoMo 问答的答案 NLL / 准确率），不是中间指标。

## 每个局部步骤必须回答的四个问题（写在设计文档开头）
1. 它服务最终目标的哪一环？（候选机制 → 下游任务 → 对比 Metis）
2. 如果结果为负，它会改变哪个决策？（不改变决策的步骤不做）
3. 它的判据是否依赖我们自己构造的代理指标？若是，是否已有与下游任务的对应关系？
4. 它是否只是在验证自己上一步的假设？若是，停止或降级。

## 停止规则
- 若某个机制在端到端对比中不优于原版 Metis（同预算、多种子），该机制不进入下一轮，不改判据后再试。
- 若所有候选机制都不优于原版，主线结论转为"诊断为何不成立"，并如实报告，而不是继续构造局部证据。
