# 设计说明：G1 等状态组织检验（真实键，离线回放）

状态：已由用户确认（2026-10-16，"认可 / 确认"）。依据 `docs/MASTER_PLAN.md` §3 的门控 G1。

## 1. 要检验的假设

H10：在**等总状态**下（$K\cdot d_b\cdot d_v = d\cdot d_v$），内容路由的分库相对单库 K1 仍有收益。

## 2. 关键前提（新的假设，需要检验）

N1 的失败来自合成的各向同性键（投影后正交性丢失）。真实键有效秩仅 5–15（E016）。因此：
- **假设 H10a**：真实键的主要信息位于少数主成分中，用一个固定的、从数据得到的 PCA 子空间（$d_b=256$）投影，不会显著损害自检索。
- 这是解析的键表示（PCA 为数据的统计量，不是学习的参数），符合"经典理论不学习"的原则。

## 3. 设计

- 数据：与 E017 相同（10 条验证 episode 记录真实写入）。
- PCA 基：**前 10 条 episode 拟合**，**后 10 条 episode 测试**（避免在测试键上拟合）。
- 各臂（等状态 = $d\cdot d_v$，即 K1 的状态）：
  - `K1_full`：单库，1024 维键（基线，状态 1×）。
  - `K4_pca_center`：4 库，每库 256 维（PCA 子空间，所有库共享同一基），路由 = 中心化键与随机固定中心的 argmax。状态 1×（等）。
  - `K4_pca_raw`：同上，路由用未中心化的键。
  - `K4_pca_random`：同上，随机路由（对照，排除"只是分了库"）。
  - `K1_pca256`：单库，256 维 PCA 键（状态 1/4，仅用于说明投影本身的损失）。
- 指标：自检索余弦（与 E017 相同），按写入次数分组。
- 统计：每个臂 3 个随机中心种子；报告配对差（相对 `K1_full`），按 episode 配对，给出 bootstrap 区间。

## 4. 判据（预先约定）

- **G1 通过**：`K4_pca_center` 相对 `K1_full` 的配对差区间不含 0 且为正。
- **G1 不通过**：区间包含 0，或为负。
- 同时必须满足：`K4_pca_center` 相对 `K4_pca_random` 为正（否则收益来自"分库"本身，而非内容路由）。
- 若 `K1_pca256` 远低于 `K1_full`，说明 PCA 256 的投影本身损失大，H10a 不成立，G1 结论需要重新考虑键表示。

## 5. 局限（必须报告）

- 只有 10 条测试 episode、约 1000 个测试键，统计功效有限。
- 自检索指标不是问答正确率。
- 随机中心未训练。
- 键的 PCA 来自合成 episode（与评测数据不同），真实评测数据的键分布可能不同。

## 6. 回滚

纯离线实验，不修改模型与代码路径，删除输出目录即可。
