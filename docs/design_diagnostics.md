# 设计说明：Phase 0 诊断实验（衰减 / 串扰 / 删除误伤）

状态：已确认（删除基线与网格规模由用户确认）。实现见 `src/diagnostics/`，结果见 `experiments/E001_diagnostics/`。
关联：`improvement_ideas/ideas_Cybernetics.md` §5 三个思路；CLAUDE.md「先诊断后改造」

## 1. 目的

在改动 Metis 之前，用合成数据区分三类误差哪一项占主导，决定先做哪个机制：

| 主导项 | 优先机制 |
|---|---|
| 衰减（有效时间常数远小于设计值，串扰可忽略） | 思路二：快慢双尺度 |
| 串扰（固定年龄下 SNR 随干扰数 N 快速下降） | 思路一：分库编目 |
| 删除误伤（误伤随键相似度 ρ 显著上升，且不能用全局 λ 解释） | 思路三：显式删除 |

本阶段不训练、不改 Metis 模型代码、不使用外部评测集。

## 2. 研究对象（参考线性记忆，不是 Metis 权重）

诊断对象是理想化的线性记忆，没有可学习参数，直接对应文档 §5 的基本形式：

$$M_{t+1}=\lambda M_t+(1-\lambda)\,k_t v_t^\top,\qquad y_t=M_t^\top q_t$$

这样误差可以直接用文档 §5 的展开式解释，不混入训练、门控或 backbone 的影响。

删除基线取两种：

- **全局遗忘**：只靠 $\lambda$ 衰减，不寻址。
- **按键擦除（GDN 式）**：$M \leftarrow M(I-\beta\hat k\hat k^\top)$，$\beta=1$，$\hat k$ 为被删键。这是 Metis 现有 GDN 局部记忆已有的机制，必须作为对照，否则思路三的增量无法说明。

## 3. 合成数据

- 键：单位向量，维度 $d\in\{64,128\}$。$d=64$ 对应文档中“约 64 个有效方向”的说法，该说法尚未核实，实验中作为待检验项。
- 值：高斯向量，维度 $d_v=d$。
- 干扰键的构造：给定目标键 $k_c$ 与相似度 $\rho$，干扰键取 $k_j=\rho k_c+\sqrt{1-\rho^2}\,n_j$ 后归一化，$n_j$ 与 $k_c$ 正交。
- 写入序列：长度 $T$，在位置 $c$ 写入目标，其余位置写入干扰条目。

**网格**：

- 年龄 $T-c\in\{1,2,4,\dots,512\}$
- 干扰数 $N\in\{8,32,128,512\}$
- 相似度 $\rho\in\{0,0.3,0.6,0.9\}$
- 衰减率 $\lambda\in\{0.9,0.99,0.999\}$
- 种子：5 个

## 4. 指标

1. **衰减**：固定 $N$、$\rho=0$，测召回余弦 $\cos(y_T,v_c)$ 随年龄的变化。对 $\log\text{SNR}$ 对年龄做线性拟合，得到有效时间常数 $\tau_{\text{eff}}$，与设计值 $-1/\ln\lambda$ 比较。
2. **串扰**：固定年龄，测信噪比 $\mathrm{SNR}=\|\text{目标项}\|/\|\text{串扰项}\|$，目标项与串扰项按文档 §5 的展开式分开计算。绘制 SNR 随 $N$、$\rho$ 的变化。
3. **删除误伤**：删除条目 $c$ 后，测其余条目读出的平均误差，按 $\rho(\hat k,k_j)$ 分组，分别对两种删除基线计算。

所有指标按种子报告均值与标准差。

## 5. 预期（待实验检验，不是结论）

- 衰减：$\tau_{\text{eff}}$ 应接近 $-1/\ln\lambda$，偏差大则说明实现或归一化有问题。
- 串扰：SNR 应近似随 $\rho$ 增大而下降，随 $N$ 下降；若与 $1/\sqrt N$ 规律偏离，记录原因。
- 删除误伤：按键擦除的误伤应随 $\rho$ 单调上升；全局遗忘无法选择性删除，误伤与 $\rho$ 无关。

## 7. 单元测试

1. **线性性**：固定系数下，$M(ax+by)=aM(x)+bM(y)$。
2. **零输入**：无写入时，状态范数随 $\lambda$ 单调不增。
3. **数值稳定性**：$T=10^5$ 时状态范数有界，无 NaN。
4. **删除后恢复**：若 $\rho=0$，删除条目 $c$ 后，$c$ 的读出为零，其余条目读出与未删除时一致（误差在浮点精度内）。

## 8. 失效模式与回滚

- 失效模式：
  - 键未归一化导致 SNR 偏差；
  - 干扰键的构造偏离目标 $\rho$（需在实验中验证实际 $\rho$）；
  - 年龄很大时数值下溢。
- 回滚：本阶段是独立脚本，不修改 Metis 代码，无需回滚。
- 异常处理：出现 NaN 或数值发散，先停止，定位原因，不调参掩盖。

## 9.5 实现时的细化（与上文不同之处）

实现后发现以下问题，已按实际口径修改，并在此记录：

1. **串扰实验改为固定目标年龄。** 目标在第 0 步写入，干扰占用最后 $N$ 步，读出在第 $A=512$ 步。原设计的“年龄网格”会把目标衰减与干扰数混在一起。
2. **SNR 被目标衰减混淆。** 干扰在最后 $N$ 步写入，几乎不衰减，而目标衰减到 $\lambda^{A}$，因此 SNR 主要反映衰减。新增指标 $\text{crosstalk\_over\_fresh}=\|y_{\text{cross}}\|/((1-\lambda)\|v_c\|)$，它以新写入目标的振幅为基准，与衰减分离。
3. **ρ=0 时 SNR 无意义。** 串扰为数值噪声量级（约 $10^{-17}$），比值不可用，记为 NaN。
4. **ρ 网格增加 0.1。** 64 维随机键的典型余弦约为 $1/\sqrt{64}=0.125$，网格需覆盖这一现实范围。
5. **删除基线的 β。** 仍为 $\beta=1$ 的按键擦除，全局基线为 $M\leftarrow\gamma M$，$\gamma\in\{0,0.5\}$。
