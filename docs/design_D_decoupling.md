# 设计说明：模块 D（解耦，分库键的正交正则）——草案，待确认

状态：**草案，待用户确认后编码**。日期：2026-10-21。
主线位置：ideas §3(5) 与 `design_holistic.md` 模块 D。前置：E001（串扰随键相关性增长）、E006 N1（随机投影破坏库内正交）、E028（快慢分组在等状态下有保留增益）。

## 1. 要检验什么

**H19**：在等总状态下，使各库的键子空间近似正交，能减少库间串扰，从而提高保留（自检索），且不依赖于训练。

**与之前结论的关系**：N1 说明随机投影会破坏正交性，因此"随机投影 + 分库"失败。D 的思路是**有意识地构造**库间近正交的键子空间，而不是随机选择。

## 2. 两种实现路线（需要你选择）

**路线 D1（结构性正交，零样本，无训练）**
- 把 PCA 的前 1024 个主成分分成两个互不重叠的块：组 1 用前 512 个，组 2 用后 512 个（按方差顺序）。
- 两组的键子空间由构造保证正交（Q_1ᵀQ_2 = 0），库间串扰在子空间层面为零。
- 代价：组 2 只看到方差较小的成分，组内信息可能变少。这是要检验的权衡。
- 与 E028 的 T2L 对照：T2L 的两组共用同一 PCA-512 基，D1 的两组使用不相交的基。

**路线 D2（学习的正交正则，需要训练）**
- 对每组的投影 Q_b 施加正则 λ_orth·‖Q_bᵀQ_{b'}‖²_F，与原有的训练目标一起优化。
- 只有路由原型是可学习的（设计 0a §12），增加 Q_b 为可学习参数会改变"等参数"的定义，需要重新确认。
- 成本高（需要训练，见 E025 的经验：约 30–40 分钟/运行，且需要多种子）。

**建议：先做 D1**。它是零样本、离线的，与 E028 同口径，能直接检验"正交构造"是否有收益。只有 D1 显示收益后，才值得做 D2。

## 3. 对照与度量（D1）

- 数据与划分：与 E028 相同（拟合 = 前 3 个对话；调参 = 第 4–5 个；测试 = 第 6–10 个）。
- 臂（等总状态 1024 行）：
  - S1：单库，全键（基线，E028）。
  - T2L：两组，共用 PCA-512 基（E028，λ 为锁定值 (0.3, 0.95)）。
  - D1：两组，正交分块基（前 512 / 后 512），路由与 λ 与 T2L 相同。
- 度量：保留曲线 AUC（与 E028 相同），逐 episode 配对，bootstrap 95% 区间。
- 串扰指标（新增，辅助）：两组键的平均绝对余弦（组间），用于确认 D1 确实降低了库间耦合。

## 4. 判据（运行前登记）

- **G5-a（D1 优于 T2L）**：D1 − T2L 的保留 AUC，两层的 95% 区间下界均 > 0。
- **G5-b（D1 优于单库）**：D1 − S1 的保留 AUC，两层的 95% 区间下界均 > 0。
- **G5-c（串扰确实降低）**：D1 的组间键余弦的均值 < T2L 的组间键余弦的均值（两层均成立）。
- **G5-d（不塌缩）**：D1 中每组的 token 占比最小值 ≥ 0.2。

三条（G5-a/b/c）都满足且 G5-d 成立，才算通过。

**注意**：D1 的组 2 只使用后 512 个主成分，可能使组 2 的信息变少。因此 G5-a 与 G5-b 必须同时检验，不能只看其中一个。

## 5. 与之前结论的一致性

- N1 指出随机投影会破坏正交。D1 不是随机投影，而是按主成分分块，因此不属于 N1 的情形，但需要在报告中说明区别。
- E027 显示竞争学习的路由只有一个独立划分。D1 的分块是确定性的，因此只有一个划分，不涉及种子变异。

## 6. 失效模式

- **组 2 信息不足**：D1 的 G5-b 可能失败（组 2 只有低方差成分）。记为负结果，并说明是组 2 的容量问题。
- **分块不优于共享基**：G5-a 失败说明"正交"本身不是收益来源。
- **D2 的训练难度**：若 D1 有效，D2 需要单独设计，本设计不包含 D2 的判据。

## 7. 回退与实现要求

- 所有改动通过开关启用，默认关闭；不修改 `metis/` 下的代码。
- 单元测试：正交分块基满足 Q_1ᵀQ_2 = 0（数值误差内）；D1 的状态递推与 T2L 相同（只改基）。
- 复用 E028 的录制键（`/hy-tmp/e028_keys.pt`）与 `eval.py` 的函数。

## 8. 需要你确认的点

1. 选择路线：D1（推荐，零样本，先检验正交构造是否有收益），还是直接做 D2（需要训练，且需要确认 Q_b 作为可学习参数对"等参数"定义的影响）。
2. 判据 G5-a、G5-b、G5-c、G5-d 的规则（区间下界 > 0；串扰的均值比较；占比 ≥ 0.2）是否合适。
3. 是否沿用 E028 的划分（测试集已用于 G4 判定，因此 D1 的结论仍须注意测试集的重复使用；如果需要，可以先用调参集判断）。
