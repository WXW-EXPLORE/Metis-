## 1. 问题陈述（来自已有实测，而非纯理论）

Metis 的记忆是每层一个矩阵 $M$（加上键的累计状态 $z$），每次 commit 写入一次。E002–E005 给出以下事实：

| 事实 | 来源 | 对设计的含义 |
|---|---|---|
| 每次写入的遗忘强度 $1-\bar\alpha$ 随层变化很大：前层约 0.85，中后层约 0.2–0.4 | E002, E003 | 遗忘速率不应是单一常数，需要多时间尺度 |
| 按键擦除的强度远弱于遗忘（$10^{-5}$–$10^{-3}$） | E002–E005 | 当前"删除"实际由全局衰减完成，删除机制不起作用 |
| 去掉遗忘使 NLL 升高约 0.40–0.43；去掉擦除的效应在 ±0.005 以内 | E004, E005 | 遗忘是记忆的主要功能；擦除在现有形式下没有价值 |
| 整个记忆是单一矩阵，所有信息叠加在同一状态 | 结构本身 | 串扰无法在结构上避免（见 E001 的参考模型结果） |
| 删除与遗忘、修改共用同一个 $\alpha$ 与 $\beta$ 的形式 | 结构本身 | 三种操作缺乏分离，缺少寻址 |

这些事实意味着：Metis 在"遗忘"上有可用的结构，但在"删除"上没有可用的机制，在"分库与多尺度"上完全没有结构。

## 2. 目标架构

保留 Metis 的骨干（Qwen3.5 冻结骨干、token 选择、读出的注意力融合），**替换局部记忆的状态结构与其更新规则**。记忆由以下模块组成。

### 模块 A：分库状态（切换系统的子系统）

$K$ 个线性记忆库 $\{M^{(b)},z^{(b)}\}_{b=1}^K$，每库独立线性递推：

$$M^{(b)}_{t+1}=\alpha^{(b)}_t\big(M^{(b)}_t-\mathcal E^{(b)}_t\big)+\mathcal A^{(b)}_t$$

- 控制概念：切换系统，子系统由路由决定激活。
- 线性性：对每个库，状态线性（固定门控时）。
- 对应 ideas §5 思路一。

### 模块 B：多时间尺度（多极点）

每库赋予不同的时间常数。结构上可分为"快"与"慢"两组：

- 快组：$\alpha$ 较小，对应短时记忆。
- 慢组：$\alpha$ 接近 1，对应长时记忆。
- 写入由输入门控分配：$\alpha$ 与写入强度 $g$ 同时由输入决定。
- 控制概念：多极点系统，极点为 $\alpha^{(b)}$ 的时间常数 $\tau_b=-1/\ln\alpha^{(b)}$。
- 对应 ideas §5 思路二。E002/E003 的层间 α 差异（0.12 与 0.9 并存）是这一设计的直接依据。

### 模块 C：显式删除（有地址的操作）

把三种操作分开，各自有独立的寻址：

- **遗忘**：全局衰减 $\alpha$，不寻址（已有）。
- **修改**：写入新值，寻址在新键上（已有的 $\mathcal A$）。
- **删除**：沿被删键 $\hat k$ 的投影，$M\leftarrow(I-\beta_d\hat k\hat k^\top)M$，$\beta_d$ 为删除增益，由输入或不确定性决定。
- 控制概念：卡尔曼式修正增益（$\beta_d$ 决定修正强度）；删除为寻址的投影。
- 对应 ideas §5 思路三。注意：E004/E005 表明现有擦除（与之同形式）几乎没有读出效应，所以删除必须是**独立设计的操作**，不能只是调大现有擦除。

### 模块 D：解耦（正交正则）

- 对分库的键施加正交或近正交正则，使不同库的键子空间尽量分离，减少串扰。
- 控制概念：解耦（减少输入之间的耦合）。
- 对应 ideas §3(5)。
- 诊断依据：E001 显示串扰随键的相关性线性增长。

### 模块 E：路由（切换律）

- 路由 $g_b(k_t)$ 由键与库中心的相似度给出，取 top-$k$ softmax（见 ideas §5 思路一）。
- 负载均衡与熵正则，防止路由塌缩。
- 监控：路由熵、各库利用率。
- 控制概念：切换律。

### 模块 F：读出

- $y_t=\sum_b g_b(q_t)\,\big(M^{(b)}_t\big)^\top q_t\,/\,(q_t^\top z^{(b)}_t+1)$，沿用 Metis 的归一化读出（读出层，不改变状态递推）。
- 控制概念：观测矩阵 $C_t$ 随路由切换。

### 模块 G（可选，用户指定的探索）：Koopman 特征提升

- 输入先经过非线性特征映射 $\phi(h_t)$，记忆状态对 $\phi$ 线性：$\mathbf x_{t+1}=A\mathbf x_t+B\phi(h_t)$。
- 这与约束 3 相容：状态对 $\phi$ 线性，非线性位于输入映射。
- 是否启用、$\phi$ 的形式（如固定随机特征或可学习特征）待你确认。
- 风险：$\phi$ 维度与参数量的增加需要等参数对照；$\phi$ 若不可学习，性能上限受限。

## 3. 控制概念与模块对照

| 控制概念 | 模块 | 所解决的问题 |
|---|---|---|
| 稳定性（谱半径 $\le 1$） | A | 状态发散；由 $\alpha\le1$ 与单位键保证 |
| 时间常数 / 多极点 | B | 遗忘速率单一；层间差异大 |
| 切换系统 / 切换律 | A、E | 信息分配；串扰 |
| 卡尔曼增益 | C | 删除强度的自适应 |
| 寻址投影 | C | 误伤；与遗忘混淆 |
| 解耦 | D | 串扰 |
| 观测矩阵 / 可观测性 | F | 读出容量（可观测性格拉姆矩阵，待实现） |
| LPV（线性参数变化） | A、B、E | 整体框架：线性状态 + 输入依赖系数 |
| Koopman 提升 | G | 非线性输入的线性表示 |

## 4. 与已有工作的差异（需在实现前补全原文核对）

## 5. 接口（草案）

- `src/holistic/`（新建，与现有 `src/diagnostics/` 分开）
  - `banks.py`：分库状态与线性递推（模块 A、B）。
  - `routing.py`：路由与负载均衡（模块 E）。
  - `delete.py`：显式删除（模块 C）。

  - `readout.py`：读出（模块 F）。

- 与 Metis 的接口：替换 `local_memory` 与 `hyper_memory` 的写入与读出，骨干与 token 选择保持不变。

## 6. 预期失效模式

- **路由塌缩**：所有 token 落入同一库。监控路由熵，超过阈值停止。
- **时间尺度退化**：快慢两组的 $\alpha$ 分布重合。监控各组 $\alpha$ 的分布。
- **删除误伤**：$\beta_d$ 过大导致相关键被误删。以 E001 的误伤曲线为基线。
- **数值发散**：状态范数随写入增长。监控状态范数与谱半径。
- **参数量与延迟**：分库与多尺度增加参数和计算。需等参数对照，延迟超过 15% 时暂停。
- **训练不稳定**：分库和路由增加优化难度。需要梯度监控。

## 12. 修订 v2（2026-10-15）：控制论修正（不改变状态形式与接口）

依据：`docs/design_0a.md` §10。本节修订模块 A、C、D、E 的定义，模块 B、F、G 不变。状态：**待确认**。

- **A 分库状态**：每库的时间常数 $\lambda_b$ 作为遗忘因子；增益由协方差 $P_b$ 给出（RLS 形式）。固定的 $\alpha_b$ 不再直接决定有效遗忘，有效极点为 $\lambda_b/(\lambda_b+\kappa^\top P_b\kappa)$。
- **B 多时间尺度**：$\lambda_b$ 为库的遗忘因子。快慢之分仍由 $\lambda_b$ 决定，但有效遗忘还取决于 $P_b$。
- **C 显式删除**：以已知地址的降秩（downdate）实现；条件 $\kappa^\top P\kappa<1$ 不满足时退回投影删除，并记录。删除强度不再是任意的 $\beta_d$。
- **D 解耦**：损失改为库内格拉姆矩阵 $W_b=\sum_j\lambda_b^{2(T-j)}\kappa_j\kappa_j^\top$ 的非对角项，替代库中心的正交。
- **E 路由**：推荐硬路由加负载均衡。切换稳定性以各库极点 $<1$ 保证有界；驻留时间作为约束。
- **F 读出、G 特征提升**：不变。

控制概念对照的更新：卡尔曼增益由 $P$ 给出（C、A）；遗忘因子即过程噪声（B）；可观测性格拉姆矩阵（D）；切换稳定性（E）。

待确认：见 `docs/design_0a.md` §11。

## 13. 当前决定（2026-10-15）

- **A 分库**：默认单库（K=1）。分库为可选项（满维度键，K 倍状态），等参数分库在键维度固定时无效（N1，E008b）。
- **B 多时间尺度**：由 RLS 的遗忘因子 $\lambda_b$ 实现；单库下尚未验证快慢组合的收益（需真实键分布）。
- **C 删除**：带遗忘权重的精确降秩，需要条目年龄（E007，精确）。
- **D 解耦**：格拉姆矩阵特征值离散度（旋转不变）。
- **E 路由**：硬路由 + 直通估计 + 负载均衡损失；实验待真实键分布。
- **F 读出、G 特征提升**：不变。G 尚未实现。

解析部分（RLS 增益、极点、降秩、格拉姆度量）不学习；学习的仅为路由中心（设计 0a §12）。
