## 三个思路的差异

**思路一（分库编目）**
- 与 MoM 最接近：都是 $K$ 个线性记忆 + 路由，未选中的库保持不变。
- 差异需要说明的部分：路由的目标。MoM 的路由服务于容量与召回，本项目要量化的是串扰的降低程度（$1/K$ 的理论预期），并用控制论的切换系统语言分析路由稳定性。这一点需要实验证明，目前是假设。
- 必须对照的基线：MoM 式 top-k 路由；随机固定路由的分库（排除“分库本身”的收益）。

**思路二（快慢双尺度）**
- 与 Titans、多时间尺度类工作相关，但 Titans 的记忆是非线性的神经网络，不满足本项目“状态线性”的约束。
- 本项目与 Titans 的差异：状态保持线性矩阵，快慢两组由输入门控分配写入。
- 需要在文档中补充：多时间尺度与 Gated DeltaNet 的全局 $\alpha$ 之间的区别。Gated DeltaNet 只有一个时间尺度。

**思路三（有地址的删除）**
- 与 DeltaNet、Gated DeltaNet 的按键擦除形式相同：$M(I-\beta\hat k\hat k^\top)$。Metis 的 GDN 局部记忆已包含这一机制。
- 因此思路三的增量不能是“按键擦除”本身，而只能是：**把删除、遗忘（全局 $\lambda$）、修改拆成三种独立操作，各自有独立的寻址方式**。这一点是实验 E3 的核心，也是需要与 GDN 基线比较的理由。
