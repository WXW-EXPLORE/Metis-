# 设计：第 5c 步 — chunk 级跨对话预测，闭式岭回归（预先登记）

日期：2026-10-22。动机：第 5b 步（N22）中 LMS 在少量配对上发散（误差 > 零预测）。估计器改为闭式岭回归，是标准做法，且不改变数据、划分、对照与判据。

## 1. 估计器
- 输入 x_c（chunk c 的键均值，PCA d=8，PCA 在 fit 上拟合），目标 x_{c+1}。
- Σ₀ = mean(x_c x_cᵀ)，Σ₁ = mean(x_{c+1} x_cᵀ)（fit 对话内的相邻配对）。
- Â = Σ₁ (Σ₀ + λ·s·I)⁻¹，其中 s = tr(Σ₀)/d（尺度归一化）。

## 2. 选择 λ（只在 tune 对话上，不碰 test）
- 网格 λ ∈ {1e-3, 1e-2, 1e-1, 1}。tune 对话 = 第 4–5 个对话（与第 5 步相同）。
- 选择规则：tune 上 X-a 增益（均值基线 NMSE − 学习预测器 NMSE）两层平均最大者。
- 注意：拟合用 fit 对话；tune 只用来选 λ。

## 3. 臂、判据与划分（沿用第 5b 步）
- 臂：学习（岭回归）、均值基线、时间打乱对照（同一估计器，训练前打乱每个 episode 内 chunk 的顺序）。
- X-a：test 上学习 vs 均值基线，episode 级 95% 区间下界 > 0，两层均成立。
- X-b：test 上学习 vs 打乱对照，区间下界 > 0，两层均成立。
- 通过 = X-a 与 X-b 均满足。

## 4. 局限
- 测试对话已在 E028、第 5 步、第 5b 步中使用过（沿用同一划分）。
- chunk 级样本少，区间宽；结论只针对该估计器与该设定。

## 结果（2026-10-22，`experiments/step5_real/results_ridge/summary.json`）

- 调参集选定 λ = 0.1（相对尺度）。
- 层 3：学习 NMSE 0.980，相对均值基线增益 0.020，区间 [−0.030, 0.065]（包含 0）；相对打乱对照增益 −0.006，区间 [−0.047, 0.031]。**X-a、X-b 均未通过。**
- 层 7：学习 NMSE 0.778，相对均值基线增益 0.222，区间 [0.195, 0.248]；相对打乱对照增益 0.186，区间 [0.143, 0.228]。**X-a、X-b 均通过。**
- **总体判定**：按预先登记的"两层均需满足"规则，未通过。

**解释**：岭回归消除了 LMS 的发散，层 7 上确实存在可跨对话泛化的 chunk 级时间结构，且不是来自打乱对照的边际统计。层 3 上没有。这个层间差异是真实的结果，不是待修正的失败；它需要在后续分析中单独解释（例如层 7 与层 3 的表示性质不同）。
