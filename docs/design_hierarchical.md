# 设计说明：层次化、有耦合的小库记忆（等状态对照）

状态：**待确认**。按 CLAUDE.md，编码前须获确认。
来源：用户的直观判断（2026-10-16）：分库不能是单库复制（那是扩容）；更有效的组织可能是"单库变小 + 库间层次组织 + 关联联动"。本文件把它形式化，并列出需要检验的假设。**本设计没有理论结果，所有结论为猜想，直到实验验证。**

## 1. 动机（已验证的前提）

- E017：真实键上，4 库内容路由比随机分库高约 0.10–0.12，但 4 库是 4 倍状态，不能与单库比较。这说明"扩容"与"组织"必须分开。
- E016：真实键低秩（有效秩 5–15），且有共同主方向。中心化路由才能均衡。
- N1：等参数的键投影（随机或分块）会破坏目标与干扰的正交性。因此"单库变小"不能简单地切分键空间。

## 2. 文献核对（已读全文的部分，其余为摘要级）

- **HMM（Mamba with Hierarchical Memory，arXiv 2608.02347，已读方法节）**：三层结构（感知记忆 = Mamba 隐状态；段落级语义 PLS = 余弦原型 + EMA 分段；长期记忆 LTM = MLP 压缩 + 余弦 top-K 检索 + 平均注入）。与我们的相同点是层次结构。差异：
  - LTM 之间没有耦合动力学（不是状态方程中的交叉项），只是按相似度检索；
  - 压缩是非线性的（SiLU MLP），不是线性状态；
  - 控制理论只用于稳定性（谱半径）与 Jacobian 秩，没有耦合稳定性（小增益）分析；
  - 额外参数约 2%，没有等状态的分库对照；
  - 局限：作者承认不适合需要精确检索大量事实的任务。
- **MoRAM**（arXiv 2506.21035）、**Raven**（pith 摘要）、**Mixture of Chapters**（arXiv 2603.21096）：路由式稀疏记忆，没有层次与耦合。
- **HMT**（arXiv 2405.06067）：三层记忆，非线性注意力，没有耦合。
- **Krotov 层次联想记忆**（2021，摘要）：理论上的层次联想记忆，没有线性状态与库间耦合的具体形式。

结论：层次化已有先例（HMM）；**库间线性耦合 + 小增益稳定性 + 等状态对照**，在检索到的材料中没有看到。需要读全文后再确认。

## 3. 形式化（猜想）

设 $L$ 层，第 $\ell$ 层有 $K_\ell$ 个库，每库 $d_\ell$ 维键。总状态 $\sum_\ell K_\ell d_\ell d_v$ 固定，与对照的单库相同。

**库内动力学**：每库是一个线性子系统（RLS 形式，见 design_0a），状态 $x_b$，遗忘因子 $\lambda_b$。

**库间耦合**：上层库接收下层库的摘要输入。写入为

$$x^{(\ell)}_{b,t+1}=A^{(\ell)}_b x^{(\ell)}_{b,t}+B^{(\ell)}_b u^{(\ell)}_{b,t}+\sum_{b'\in\mathcal N(b)}G_{bb'}\,x^{(\ell-1)}_{b',t}$$

其中 $G$ 为耦合增益，$\mathcal N(b)$ 为相邻（如按键相似度或层次父子）库。状态对 $x$ 线性，耦合是非线性系数（由路由与增益给出），符合约束。

**稳定性（控制论判据，待证明）**：若 $\max_b\|A_b\|+\sum_{b'}\|G_{bb'}\|<1$（小增益条件），则整体收缩，状态有界。这给出耦合强度的上界，是本设计区别于 HMM 的理论点。

**键表示（待解决）**：N1 显示等参数的键投影不可行。候选：
- (a) 上层键为低维摘要（如下层键的聚类中心），下层键保持完整维度但只存一部分库；
- (b) 不切分键，只切分值或时间尺度（多时间尺度作为层次），避免投影；
- 两者都需要在真实键上检验（E016/E017 的数据）。

## 4. 对照（等状态）

| 臂 | 结构 | 总状态 |
|---|---|---|
| A | 单库 RLS | $S$ |
| B | 扁平 $K$ 库，内容路由，无耦合 | $S$（需键表示，见 §3） |
| C | 层次 $L$ 层，无耦合 | $S$ |
| D | 层次 $L$ 层，有耦合（小增益） | $S$ |

主比较：C 对 B（层次本身）、D 对 C（耦合本身）、D 对 A（整体组织）。都在等总状态下。

## 5. 指标

- 第一阶段（离线、真实键，沿用 E017）：自检索余弦、串扰随写入数的曲线、路由均衡（E016）。
- 第二阶段（删除与覆盖更新）：降秩的近似误差（已知闭环问题，见 N10），删除后残留与误伤。
- 第三阶段（训练）：需要从头训练，并与原版等预算比较（1b 的协议）。

## 6. 判定（预先约定）

- D 相对 C 在第一阶段的配对差（按写入次数分组）区间不含 0 且为正：支持耦合有益。
- C 相对 B 同理：支持层次有益。
- 任一差异区间包含 0：不能判定，报告为无差异。
- 若 D 在耦合增益接近小增益边界时反而变差：支持"耦合引入串扰"，需记录为负结果。

## 7. 失效模式与风险

- **耦合引入串扰**：耦合把不相关信息也传入上层。缓解：耦合只传摘要，且增益受小增益条件约束。
- **层次只是路由的重新包装**：层次的收益可能与路由相同（E017 中 K4 已显示路由收益）。需要用随机分层作对照。
- **容量混杂**：必须等状态。
- **N1 的键问题**：若键表示不可解，等状态的分库将无法成立（见 §3）。

## 8. 回滚与开关

- 耦合增益为 0 时，结构退化为无耦合的独立库，必须与对应的无耦合结构逐位一致（单元测试）。
- 层数为 1 时退化为扁平库。
- 所有新机制默认关闭。

## 9. 接口（草案）

- 扩展 `BankedLinearMemory`：增加 `levels` 与 `coupling`（矩阵 $G$），与现有接口保持一致（`write`、`read`、`delete`、`state`）。
- 新增单元测试：耦合为 0 时的一致性；小增益判据的数值检查；状态有界（长序列）。
