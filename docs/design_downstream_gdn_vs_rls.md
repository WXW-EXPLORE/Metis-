# 设计：下游对比 — 原版 GDN 记忆 vs 候选 RLS 记忆（LoCoMo 问答，同预算，预先登记）

日期：2026-10-24。状态：**已登记，运行前锁定**。依据：用户同意（"先测试，不要下定论"）。

## 1. 要回答的问题（测试，不下结论）
在相同数据、相同训练预算、相同骨干下，候选的 RLS 记忆（K1 臂）与原版 Metis 的 GDN 记忆（从头训练）在 LoCoMo 问答的答案 NLL 上是否有可检出的差异。

## 2. 臂
- **K1（候选，RLS 单库，abs 读出）**：沿用 E025 的 `runs_abs/K1_full_s{0,1,2}`（已完成）。
- **GDN（原版记忆形式，从头训练）**：骨干冻结；记忆参数（W_k、W_v、query_proj、归一化与门控 α/β）按 E013 的 baseline 变体从随机初始化训练；门控参数保持可训练（与原版一致）。

## 3. 共同设置（与 K1 一致）
- 数据：LoCoMo，前 5 个对话拟合（训练），去掉超过 3000 token 的 episode（712 个 QA 行）；测试：后 5 个对话的前 100 个 QA 行（答案 NLL）。
- 训练：300 步，每步累积 4 个 episode，学习率 1e-4（warmup + 余弦衰减），梯度裁剪 1.0。
- 种子：0、1、2。

## 4. 判据（登记）
- 每个种子的测试集逐 episode NLL，配对差 D = NLL(K1) − NLL(GDN)。
- 报告：三种子平均的 D 与 episode 级 bootstrap 95% 区间；每个种子的 D。
- **仅作测试性判定**：区间上界 < 0 记为"K1 显著更好"；区间下界 > 0 记为"GDN 显著更好"；否则"无可检出差异"。本步不据此下结论。

## 5. 等参数说明（必须报告）
- K1 的可训练参数 125,884,416；GDN 额外包含门控参数（每层两个线性层），需要在结果中报告实际数值并说明差异。

## 6. 局限
- 测试集已在 E028/第 5 步中用于其他判定（本次是 LoCoMo 问答 NLL，与那些判定不同，但划分相同）。
- 只有 3 个种子，训练只有 300 步。结论只适用于本预算。

## 7. 结果（2026-10-24，测试性，按 §4 规则报告，不作结论）

| 种子 | K1 测试 NLL | GDN 测试 NLL | D = K1 − GDN（episode 均值） |
|---|---|---|---|
| 0 | 2.895 | 2.662 | +0.233 |
| 1 | 3.026 | 2.745 | +0.280 |
| 2 | 3.051 | 2.716 | +0.335 |

- 三种子平均的 D：**+0.283，95% 区间 [0.172, 0.398]**（episode 级 bootstrap）。
- 按登记规则：区间下界 > 0，记为 **"GDN 显著更好"**（在本预算、本训练设置下）。
- 可训练参数：K1 125,884,416；GDN 125,925,392（差 40,976，约 0.03%，为门控参数）。
- 初始（未训练）NLL 不同：K1 为 9.8–11.1，GDN 为 7.9–9.4。两者起点不同，比较的是 300 步训练后的结果。

**需要注意（测试性，不作结论）**：
- 只有 300 步、3 个种子、100 个测试 QA 行，结论只适用于此预算。
- RLS 记忆与 GDN 的训练超参（如 λ=0.9）未调优，GDN 的超参沿用原版设计。
- 数据为 LoCoMo 前 5 个对话（去掉超过 3000 token 的 episode）。
