# 设计草案：R1 — 快慢分工的消融（等存储预算下的率失真）

状态：**草案，待确认后编码**。日期：2026-10-22。
主线位置：收窄主线第 2 步（快慢分工消融）。依据：`design_R0c_predictive.md`（线性预测规律可辨识）、`theory_innovations.md` §2、§7。

## 1. 要检验什么

在**相同存储比特预算**下，慢层学习的预测 + 快层存储的创新残差，是否比直接存储原始经历（纯快层）更能准确重建经历。

这是率失真的问题：预测能降低被存储量的方差，因此相同比特数下误差更小。这一点是已知的（预测编码 / 创新的率失真关系），本设计的目的是在我们的框架（线性载体、慢速学习、双时间尺度）中**量化并检验它**，而不是声称新发现。

## 2. 数据（线性高斯，结构已知，延续 R0c）

- 状态 s_{t+1} = A s_t + w_t，w_t ~ N(0, Q)，观测 x_t = C s_t + v_t，v_t ~ N(0, R)。
- 维度：状态 m = 4，观测 d = 16（C 为随机列正交的 16×4 矩阵），R = 0.1 I。
- A 的谱半径 0.9（与 R0c 相同的正交构造）。
- 每个种子独立生成 A、C、训练与测试序列。

理由：观测维度高于状态维度，使得观测本身有冗余，预测（由状态估计给出）能真正降低存储量。这比 R0c（x = s）更接近"经历被记录为高维观测"的情形。

## 3. 臂（等比特预算）

每步允许存储 b 比特/坐标（b ∈ {2, 4, 6, 8}，均匀量化，范围按训练集的 ±4σ 设定，σ 为该量的方差）。

- **F（纯快层）**：直接量化原始观测 x_t。
- **FS（快慢分工）**：慢层学习状态转移与观测参数 θ（见下），用卡尔曼预测器给出 x̂_{t|t-1}，快层量化创新 r_t = x_t − x̂_{t|t-1}，重建 x̂ + r̂。
- **S（纯慢层，无快层存储）**：只用预测器（零比特存储的残差），作为下界对照（其误差等于预测误差，与 b 无关）。

慢层参数 θ 的学习（线性，双时间尺度）：
- 用预测误差的随机逼近更新 A、C（学习率 γ_n = c/(n+n_0)，与 R0b 一致），快层为卡尔曼滤波（给定 θ，线性递推）。
- 学习期间，存储的创新使用存储时的 θ（版本记录）；重建使用各自存储时的 θ 版本。本阶段不检验版本漂移的代价（留给第 3 步），只记录其存在。

## 4. 度量

- **重建 MSE**：测试序列上 E‖x_t − x̂_t^{recon}‖² / E‖x_t‖²，对每个 b 与每个臂。
- **预测 MSE**：E‖x_t − x̂_{t|t-1}‖² / E‖x_t‖²（只与慢层相关，与 b 无关）。
- **存储率**：每步比特数 = b × d（F、FS 相同），用于证明预算相等。

## 5. 判据（草案，运行前登记）

- **R1-a（分工有收益）**：在每个 b 上，FS 的重建 MSE 低于 F，逐种子配对差的 95% 区间下界 > 0。
- **R1-b（收益随 b 变化符合率失真预期）**：FS 相对 F 的 MSE 比值，随 b 增加保持稳定或缩小；不得在高 b 时反向。
- **R1-c（慢层有效）**：慢层的预测 MSE 显著低于 "x̂ = 0" 的基线（即 S 的预测误差 < 1）。
- **R1-d（可辨识）**：A、C 的估计误差随训练长度减小（与 R0c 的 P3 一致）。

通过 = R1-a、R1-b、R1-c、R1-d 全部满足。

## 6. 失效模式与解读

- **R1-a 失败**：慢层的预测不足以降低创新方差，或量化在该尺度下不敏感。此时分工在该设定下无收益，主张需要修改或转为负结果。
- **R1-c 失败**：慢层未学到动态，分工无意义，应先回到 R0c 检查学习。
- **解读限制**：本设计只检验线性高斯情形下的率失真收益。它不检验干预、泛化到新情境、或版本漂移（这些在第 3、4 步）。

## 7. 与理论的对应

- 理论笔记 §2：创新 r_t 与过去不相关，若预测器最优则白噪声。R1-c 检验预测器是否接近最优（预测 MSE 与理论值 tr Q 的比较，作为辅助诊断）。
- 理论笔记 §6：双时间尺度的步长条件。R1-d 与 R0b 的学习率衰减一致。

## 8. 需要确认的决定

1. 量化方案（均匀、范围 ±4σ）是否可接受，还是用更能代表率失真的方案（例如熵编码的估计）。
2. 观测维度 d=16、状态维度 m=4、R=0.1 是否合适。
3. 判据阈值：R1-b 的"比值稳定"是否需要数值阈值（我倾向先定性检验，再定量）。
4. 是否同意本步只做线性高斯，非线性留给后续。

## 9. 参数选定与结果（2026-10-22）

### 9.1 预试验选参（`experiments/R1_division/pilot.py`，种子 900–902，与正式实验无重叠）
- 预试验修正：初版卡尔曼递推漏掉因子 A（x̂_{t+1|t} = A(x̂_{t|t-1} + K r_t)），修正后新息方差不再超过原始方差。
- 量化范围：b=8 时裁剪率，k=2 为 4.6%，k=3 为 0.3%，k=4 为 0.006%。规则"<1% 的最小 k"选定 **k=3**。
- (d, R)：规则"b=4 时 FS/F 比值在 0.5–0.9，取 d 最小"。候选中 d=8 且满足条件者为 **d=8，R=0.5**（比值 0.68）。R=0.05、0.1 的比值 ≤0.47（收益过大，按规则排除）。

### 9.2 正式实验（oracle 参数，`experiments/R1_division/run.py`，种子 0–19）
- 参数：d=8，R=0.5，k=3，N=4000，比特 b ∈ {2, 4, 6, 8}。

| 比特 b | F（直接量化） | FS（预测 + 量化创新） | F − FS，95% 区间 | 比值 FS/F |
|---|---|---|---|---|
| 2 | 0.339 | 0.228 | 0.110 [0.107, 0.113] | 0.67 |
| 4 | 0.0140 | 0.0093 | 0.0047 [0.0046, 0.0048] | 0.67 |
| 6 | 0.00153 | 0.00085 | 0.00067 [0.00058, 0.00077] | 0.57 |
| 8 | 0.00082 | 0.00037 | 0.00045 [0.00035, 0.00054] | 0.49 |

- **R1-a（分工有收益）**：通过。每个比特的 F−FS 区间下界均 > 0。
- **R1-b（不在高比特反向）**：通过。比值在所有比特上都 < 1。
- **R1-c（慢层有效）**：通过。慢层预测误差 0.677，低于零预测基线 1.0。
- **R1-d（可辨识）**：本步未检验。需要在线学习 θ，属于第二步。

### 9.3 解释与待查问题（⚠️）
- 这一结果基本符合率失真的预期：预测降低了被存储量的方差，所以同样比特数下误差更小。它量化了这一效应，但不是新发现。
- **待查**：高比特时比值（0.49）低于新息与原始的方差比（0.68）。按高比特率理论，两者应接近。可能原因包括：各坐标的方差不同导致的量化范围效应，或测量噪声在新息中的比例。在声称"收益随比特变化"之前需要查清楚，本次不作结论。
- **未做的部分**：慢层参数由数据学习（R1b）。本次用的是真实参数，因此结果是理论上界，不是可实现的效果。

## 10. R1b 设计（在线学习慢层，预先登记，2026-10-22）

**慢层**：观测域一步线性预测器 M_t（D×D），x̂_t = M_{t−1} x_{t−1}。学习：归一化 LMS 随机逼近
M_t = M_{t−1} + γ_t (x_t − M_{t−1} x_{t−1}) x_{t−1}ᵀ / (ε + ‖x_{t−1}‖²)，γ_t = γ₀ / (1 + t/τ)（Robbins–Monro 形式）。
参考解：M* = Σ₁Σ₀⁻¹（由真实协方差精确计算，仅用于判据，不用于学习）。

**快层**：创新 r_t = x_t − x̂_t，量化（b 比特，范围 ±3·RMS，与 R1 相同）。重建为闭环递推：x̂^rec_t = M_{t−1} x̂^rec_{t−1} + r̂_t。
F 臂与 R1 相同（直接量化 x）。

**参数**：γ₀、τ 由预试验选定（种子 900–902；选择规则：收敛到 M* 的相对误差在 N=4000 时最小且不发散）。

**判据（运行前登记）**：
- R1-d（可辨识 / 收敛）：‖M_N − M*‖_F / ‖M*‖_F 在 N=4000 时 < 0.1，且均值随 N ∈ {200, 1000, 4000} 单调下降。
- R1-a′：F − FS（学习的慢层）的 95% 区间下界 > 0，对所有 b。
- R1-b′：FS/F 比值 < 1，对所有 b。
- R1-c′：学习的预测 NMSE < 1，且与 M* 的预测 NMSE 相对差 < 10%。

**已知的未覆盖项**：解码器需要 M_{t−1} 的历史（版本问题）。本步假设解码器知道每步的 M 版本，其存储代价不计入比特预算。版本一致性（P2）属于第 3 步，不在本步判定。

## 11. R1b 结果（2026-10-22，20 个种子，`experiments/R1_division/results_r1b/`）

| 判据 | 结果 | 判定 |
|---|---|---|
| R1-d 收敛到 M*（N=4000 相对误差 < 0.1，单调） | 相对误差 0.414 (N=200)、0.225 (N=1000)、0.124 (N=4000)；单调下降，但 0.124 > 0.1 | **未通过** |
| R1-a′ F − FS（学习的慢层）区间下界 > 0 | b=2–8 均为正，区间不含 0 | 通过 |
| R1-b′ FS/F < 1 | 0.93、0.93、0.83、0.77 | 通过 |
| R1-c′ 学习预测 NMSE < 1 且接近 M* | 0.737 vs 0.728（相对差 1.3%） | 通过 |

**解释**：
- 收益依然为正，但比 oracle（0.49–0.67）小。原因是慢层的预测误差没有收敛到 M*，残留的误差进入了创新。这说明"分工的收益"依赖于慢层学习的质量，而不是单纯的分工结构。
- R1-d 失败的原因是我们选定的步长在 N=4000 内还没有充分收敛（预试验已显示最佳值为 0.13，接近阈值）。这是数据量与学习速度的问题，与第 0 节的讨论一致。
- 按规则，阈值不因结果修改。若要改善收敛，需要更长的序列或更好的步长调度，并作为新的预先登记。

**记录**：负结果 N19（见 `docs/negative_results.md`）。

## 12. R1b′：更长序列的预先登记（2026-10-22，运行前登记）

**动机**：N19。R1b 在 N=4000 时 R1-d 未达到 0.1（0.124），单调下降但未收敛。

**唯一改变**：序列长度 N = 20000（R1b 为 4000）。其余不变：γ₀=0.1，τ=100（不重新选参）；d=8，R=0.5；比特 {2,4,6,8}；量化范围 ±3·RMS；种子 0–19；M* 由真实协方差计算。检查点 N ∈ {200, 1000, 4000, 20000}。

**判据（与 R1b 相同，判定点改为 N=20000）**：
- R1-d′：‖M_N − M*‖_F/‖M*‖_F < 0.1 at N=20000，且均值随 N 单调下降。
- R1-a′、R1-b′、R1-c′：同 §10，在 N=20000 上判定。

**为什么不改步长**：预试验的选参是在 N=4000 上完成的，若在 N=20000 上重新选参，就是对同一检验的再调参。保持步长不变，使结果只反映序列长度的影响。若 R1-d′ 仍失败，则说明在该步长调度下收敛速度不足，需要单独登记步长调度的检验，而不是在此结果上修改。

## 14. 第 3 步：版本一致性（预先登记，2026-10-22）

**情形**：前半段（t < T_s）为环境 1（观测映射 C_1），后半段为环境 2（C_2，知识更新）。慢层 M 在线学习（同 R1b 的步长调度，γ₀=0.1，τ=100）。快层在前半段存储了量化创新（b=4）。

**问题**：慢层在后半段更新后，用于解码前半段的参数是哪一个？

**三种解码方式**（比较前半段的重建误差）：
- **V0（无版本）**：解码器用当前（最终）参数 M_N 解码全部历史。
- **V1（历史版本，理想）**：解码器使用每一步存储时的参数 M_t。版本代价不计入（上界）。
- **V3（分块版本）**：参数每 L=500 步冻结一次，存储每块的版本号。额外代价 = log₂(块数)/L 比特/步，计入报告。

**设置**：d=8，R=0.5，b=4，N=20000，T_s = 10000，种子 0–19；C_2 为 C_1 的一个随机正交变换（谱不变，但映射不同）。

**判据（运行前登记）**：
- V-a（漂移有代价）：V0 的前半段 NMSE ≥ 1.5 × V1 的前半段 NMSE（均值）。
- V-b（分块版本足够）：V3 的前半段 NMSE ≤ 1.1 × V1 的前半段 NMSE（均值），且额外代价 ≤ 0.02 比特/坐标/步。
- V-c（新知识被学到，记录）：后半段学习预测 NMSE 低于"沿用 C_1 参数"的预测 NMSE（不作为通过判据，仅用于解释稳定性与可塑性的权衡）。

**说明**：若 V-a 不成立（漂移可忽略），则版本问题在该设定下不构成主要代价，结论相应改写，不修改判据。

## 16. 第 3 步的改进：缩短块长（预先登记，2026-10-22）

**动机**：N20。L=500 时 V-b 未通过（V3/V1 = 1.81）。

**唯一改变**：块长 L ∈ {50, 100}（L=500 已测）。其余设置与 §14 相同（d=8，R=0.5，b=4，N=20000，T_s=10000，种子 0–19，同一步长调度）。

**代价计算**：版本索引每块记录一次，代价 = log₂(块数)/(L·d) 比特/坐标/步。块数按前半段（10000 步）计。

**判据（与 §14 相同，阈值不改）**：
- V-a：V0/V1 ≥ 1.5。
- V-b′：V3/V1 ≤ 1.1 且代价 ≤ 0.02 比特/坐标/步。

**选择规则**：若 L=50 与 L=100 都满足 V-b′，选代价较低者（L=100）；若只有 L=50 满足，选 L=50；若都不满足，记为负结果，不再缩短（继续缩短会使代价超过 0.02）。

## 17. 第 3 步缩短块长的结果（2026-10-22，20 个种子）

| 块长 L | V0/V1 | V3/V1 | 代价（比特/坐标/步） | V-a | V-b′ |
|---|---|---|---|---|---|
| 500（§15） | 12.7 | 1.81 | 0.0011 | 通过 | 未通过 |
| 100 | 12.7 | 1.113 | 0.0083 | 通过 | 未通过（1.113 > 1.1） |
| **50** | 12.7 | **1.048** | **0.0191** | 通过 | **通过** |

**按 §16 选择规则**：只有 L=50 满足 V-b′，因此选定 **L=50**。

**注意**：L=50 的代价 0.0191 接近 0.02 的上限。继续缩短块长会使代价超过上限，因此 L=50 是该代价约束下的边界。

**结论（在该设定下）**：版本漂移确实有代价（V0 为理想情形的 12.7 倍），按 50 步分块记录版本可以把误差控制在理想情形的 1.05 倍以内，代价约 0.019 比特/坐标/步。
