# 设计说明：G1c，数据自适应的路由原型（竞争学习 + 内稳态平衡），等总状态

状态：已确认（用户，2026-10-16："确认，如果能借鉴人脑最好了"）。判据在运行前登记。
依据：`docs/MASTER_PLAN.md` H10b（⚠️）、H15（❌），E022（负载对随机中心敏感），E019/E018 的 G1 系列。

## 1. 动机与借鉴（区分控制论与认知神经科学）

- **控制论**：分库是切换系统，切换律（路由）决定子系统激活。若切换律与数据无关，子系统的"属性"无法匹配输入，负载集中即是失配的表现。路由原型应被数据塑造，使每个子系统的响应区域与输入分布匹配（一种自适应的切换律）。
- **认知神经科学（类比，需文献核实）**：
  - 竞争学习与侧抑制：输入由竞争的单元表示，胜者更新（已有的 FSCL/ART 类理论）；
  - 内稳态可塑性（homeostasis）：单元的使用率被平衡，防止少数单元垄断（对应 FSCL 的"良心"机制，DeSieno 1988）；
  - 模式分离（齿状回）与模式补全（CA3）：相似输入被分到不同表示以减少干扰，这对应分库要求的"可区分的子系统"。
- 文献检索（摘要级）：FSCL/良心机制在 [FSCL 平衡聚类](http://www.ideal.ece.utexas.edu/papers/arindam04tnn.pdf) 与 [DeSieno 良心机制](https://www.inf.ufrgs.br/~engel/data/media/file/cmp121/conscience%20competitive%20learning.pdf) 中有研究；其局限：良心机制只适用于各簇先验相等的数据。海马模式分离见 [Science 2007](https://www.science.org/doi/10.1126/science.1135801)。**本设计不假设数据先验相等**，因此平衡必须作为可检验的参数。

## 2. 机制（全部为解析或学习，无人为全局参考量）

- 原型 $c_b\in\mathbb R^{1024}$（单位向量），由数据在线学习（竞争学习）：
  - 评分：$s_b=c_b^\top\hat k-\beta\,(u_b-1/K)$，其中 $u_b$ 为库 $b$ 的使用率（内稳态项，$\beta$ 为内稳态强度）。
  - 胜者 $b^*=\arg\max_b s_b$：$c_{b^*}\leftarrow\mathrm{normalize}(c_{b^*}+\eta(\hat k-c_{b^*}))$。
  - 使用率：$u\leftarrow(1-\rho)u+\rho\,e_{b^*}$。
- 训练：只用拟合集（seed 9000 前 10 条 episode 的键，按顺序单次遍历）。测试时原型冻结，路由使用同样的评分（含内稳态项，取拟合结束时的使用率）。
- 超参数（预先固定，不调参）：$\eta=0.05$，$\rho=0.01$，$\beta\in\{0,1\}$。

## 3. 臂（等总状态：K=4，每库 256 维 PCA 键，与 E019/E021 相同）

| 臂 | 路由 |
|---|---|
| K1_full | 单库，1024 维（基线） |
| K1_pca256 | 单库，256 维（投影代价） |
| K4_random | 随机固定中心（E019 的 K4_raw，3 个种子） |
| K4_CL | 竞争学习，无内稳态（β=0） |
| **K4_CL_cons** | 竞争学习 + 内稳态（β=1）——主臂 |
| K4_balanced_free | 内容无关的等数量随机分配（每 episode 严格均衡）——负载控制对照 |

## 4. 数据与指标

- 拟合：seed 9000 前 10 条 episode（原型学习）；PCA 基同样来自此集。
- 测试：**新的 seed 9500，20 条 episode**（所有前序实验都未使用）。
- 指标：每 episode 的自检索余弦（同 E018/E019）；配对按 episode（种子先平均）；bootstrap 95%。
- **负载按每个种子单独报告**（不取平均，吸取 E022 的教训）：每个种子的最大库占比与归一化熵。

## 5. 判据（预先登记，两层分别判定）

- **G1c-a（负载达成）**：K4_CL_cons 每个种子的最大库占比的中位数 < 0.40。若不满足，后两条不能归因于路由（只能归因于负载）。
- **G1c-b（优于单库）**：K4_CL_cons − K1_full 的区间下界 > 0。
- **G1c-c（内容的作用超过负载平衡）**：K4_CL_cons − K4_balanced_free 的区间下界 > 0。
- **G1c 通过**：三条同时满足，且两层都通过。
- 报告（非判定）：K4_CL_cons − K4_random、K4_CL − K4_CL_cons（内稳态的作用）。

## 6. 局限（预先声明）

- 自检索指标，不是问答正确率。
- 测试 20 条 episode；种子 3 个。
- 键分布来自合成 episode（真实评测数据可能不同）。
- 类比（大脑）为启发式，不构成证据；结论只针对本设置。
- 原型在完整 1024 维空间学习，但分库键为 256 维 PCA 投影。
