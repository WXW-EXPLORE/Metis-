# 设计说明：R0b — 数据规模与学习率衰减（预先登记，运行前不修改）

日期：2026-10-22。依据：R0 结果（`design_R0_regularity.md` §9，N18）。
R0 中 T3 失败（固定 η 下规律被无关经历冲掉）、T4 因严格单调未通过（0.0005 下降）。R0b 把数据规模与学习率调度作为被检验的变量。

## 1. 要检验什么

- 数据规模（N_train）与学习率调度对 T1–T4 的影响。
- 能否在较大的数据规模下，让慢速规律同时满足 T1（泛化）与 T3（稳定性）。

## 2. 条件（2 × 2）

| 条件 | N_train | 学习率 |
|---|---|---|
| C1（R0 基线） | 5000 | 固定 η = 0.01 |
| C2 | 5000 | 衰减 η_t = 0.01 / (1 + t/1000) |
| C3 | 50000 | 固定 η = 0.01 |
| C4 | 50000 | 衰减 η_t = 0.01 / (1 + t/1000) |

- 其余参数与 R0 相同：d = 64，m = 4，σ = (3, 2, 1.5, 1)，噪声 0.3，N_test = 2000，N_drift = 5000，20 个种子。
- 衰减条件下，T3 的漂移在训练结束后以最终学习率 η_N 冻结进行（与 R0 的"继续输入无关经历"对应，但学习率不再衰减到零以外）。
- 学习曲线检查点：{100, 500, 1000, 2000, 5000, 20000, 50000}（N_train = 50000 时包含全部检查点）。

## 3. 判据（与 R0 相同，T4 容差预先登记）

- **T1**：D = 误差(随机 U) − 误差(学习 U) 的 95% 区间下界 > 0，且占神谕间隙比例 ≥ 0.5。
- **T2**：无规律对照的 D_null 区间包含 0，且 |D_null| < 0.25 |D_T1|（同一条件下的 T1）。
- **T3**：无关经历漂移后最大主角余弦均值 ≥ 0.95。
- **T4**：学习曲线（种子均值）在相邻检查点之间的任何下降 ≤ 0.001（**本容差在运行前登记**，R0 中未登记），且 N_train 对应的最终值 ≥ 0.95。

每个条件独立判定。R0b 的结论：哪些条件满足全部判据；数据规模与学习率调度各自的作用。

## 4. 解读规则（预先登记）

- 若 C2 满足 T3 而 C1 不满足：说明学习率衰减（时间尺度分离）是稳定性的关键。
- 若 C3 满足 T4 而 C1 不满足：说明 T4 的失败与数据量有关。
- 若 C3 仍不满足 T3：说明数据量不能替代时间尺度分离。
- 不因结果修改上述规则。

## 5. 失效模式

- 衰减过快：η 在大 N 时过小，U 不再学习（T1 或 T4 失败）。
- 衰减过慢：与固定 η 相似，T3 失败。

## 6. 结果（2026-10-22，20 个种子）

| 条件 | T1 | T2 | T3（漂移后主角余弦） | T4（最大下降） | 全部通过 |
|---|---|---|---|---|---|
| C1：5k，固定 η | 通过（0.975） | 通过 | 未通过（0.036） | 通过（0.0005） | 否 |
| C2：5k，衰减 | 通过（0.995） | 通过 | 未通过（0.546） | 通过（0.0） | 否 |
| C3：50k，固定 η | 通过（0.974） | 通过 | 未通过（0.052） | 通过（0.0004） | 否 |
| C4：50k，衰减 | 通过（0.999） | 通过 | **通过（0.992）** | 通过（0.0） | **是** |

解读（按 §4 预先登记的规则）：
1. 只增加数据量（C3）不能解决稳定性：固定学习率下，T3 仍失败。
2. 只做学习率衰减（C2）也不够：5k 样本下衰减尚未充分，T3 仍失败（0.546）。
3. 只有两者同时满足（C4）时，规律既能形成（T1），又在无关经历之后保持（T3）。
4. T4 在四个条件下都满足（最大下降 ≤ 0.001），容差问题不再是瓶颈。

**需要注意的局限**：
- T3 的测量是在学习率冻结于最终值 η_N ≈ 0.0002 之后进行的。稳定性部分来自"学习率已经很小"，也就是**稳定性与可塑性之间的权衡**：学习率越小越稳定，但对新规律的学习也越慢。这一点尚未检验，需要在下一步测试"漂移之后能否学习新规律"。
- 只有一种数据分布（4 个潜在因子，固定谱）。
- 这些都是合成数据上的数值结果，不涉及 Metis 模型。

**记录**：C4 的结果是正面结果，按规则记录；C1–C3 的失败与 N18 一致。下一步需要预先登记的检验：**漂移之后能否学习新规律（可塑性）**。
