# 设计说明：E029 — RLS 与 GDN 差距的诊断（B）

日期：2026-10-25。状态：**运行前登记**（判据在看到 pilot 结果前写定，运行后不得修改）。

## 1. 目的与边界

D = K1 − GDN = +0.283（`docs/design_downstream_gdn_vs_rls.md` §7）。原因未知，可能是超参、训练预算或结构。本实验只做**诊断**：找出是否存在一个单变量改动能显著缩小差距。它不是新的对比结论，任何候选都必须在正式测试划分上用 3 个新种子重新登记后才能成为结论。

## 2. 为什么不用测试集调参

`load_qa` 的测试划分为第 6–10 个对话，`n_test=100` 的评测就是测试集。调参若在此进行，会污染 D 的结论。因此新增 `--pilot`（默认关闭）：

- 训练拟合集 = 前 4 个对话的 episode；
- pilot 评测集 = 第 5 个对话的 episode（前 100 行）；
- **测试集不被读取**。

代价：pilot 运行的训练数据少于正式运行（约 4/5），因此 pilot 绝对值不可与正式结果比较，只比较 pilot 内部的配对差。

## 3. 设计（单变量，相对基线 P0）

| 运行 | 臂 | 改动 | 种子 |
|---|---|---|---|
| P0 | K1_full | 基线：λ=0.9，lr=1e-4 | 10 |
| P1 | K1_full | λ=0.99（只改 λ） | 10 |
| P2 | K1_full | lr=3e-4（只改学习率） | 10 |
| P3 | GDN | 基线：lr=1e-4 | 10 |

- 种子 10 不与正式种子 0–2 重叠。
- 只使用一个 pilot 种子，因此结论只能是方向性的，不构成多种子结论。
- 每个运行约 20–40 分钟，顺序执行（单 GPU）。

## 4. 判据（预先写定）

以 P0 为参照，逐 episode 配对计算 NLL 差 d_i = NLL_变体 − NLL_P0，用 bootstrap 给出 95% 区间：

- **候选**：mean(d) < −0.05 且区间不含 0 → 该单变量改动值得在正式划分上验证；
- **无效**：区间含 0 或 |mean(d)| < 0.05 → 该变量不是主要原因；
- 其余情况记为"不确定"，不做结论。

P3 与 P0 的差只用于回答"pilot 上 GDN 与 RLS 的差距是否与正式结果同向"（若同向，pilot 有参考价值）。

## 5. 失效模式与回滚

- NaN 或梯度爆炸：按 CLAUDE.md 停止，定位原因，不调参掩盖。
- `--pilot` 默认关闭，正式运行命令不变。
