# 会话纪律与目标锚定

## 锚定（防跑偏）
1. 开始任何新任务前，先引用 CLAUDE.md 中的主线目标，
   用一行说明本任务如何服务主线；说不清楚就停下来问我
2. 每完成一个子任务，回复末尾一行标注：本任务对主线的贡献
3. 发现自己在做"感觉有用但主线没要求"的事，立即停下报告

## 会话交接（连续性）
1. 新会话开始：先读 PROGRESS.md，复述当前阶段、关键决策、
   卡点、下一步，经我确认后再动手
2. 任务告一段落或 /clear 前：更新 PROGRESS.md，包含
   已完成 / 决策及理由 / 卡点 / 下一步具体动作

## 压缩时必须保留
实现状态、文件路径、关键决策及否决理由、失败测试、下一步
## 压缩时可以舍弃
来回讨论、已写入 PROGRESS.md 的内容

## 会话纪律（控 token）
1. 单个任务完成即提醒我 /clear，禁止继续闲聊拖长历史
2. 上下文用量过半时主动提醒我 /compact
3. 读超过 5 个文件的任务，建议拆给子代理，主线程只留摘要
